# 设置页终端界面

## 目标
用户执行 /pi-company:setting 后在输入栏位置得到符合布局规范的单页设置界面，操作全部交给控制器，保存结果如实显示。

## 业务规则（来源：spec）
- settings-page：上下蓝线始终等于终端可用宽度，内容区独立限宽（72 列上限）且窄屏不超宽；主页各区块之间各一行空白、标题与范围行之间不插空行；宽度足够时提示合为"←→ 角色 · ↑↓ 字段 · Tab 范围 · Enter 修改 · Esc 关闭"一行，窄屏折行仍可操作；高度不足先压缩空白；当前角色方括号突出，仅选中值行蓝底，来源灰色；模型页依次为标题、搜索行、列表、提示，思考页与 MCP 页无搜索行；候选页标题为"<角色> 模型选择 / 思考选择 / MCP 选择"；整个设置只打开一次界面，视图切换不关闭重建、不闪屏；主页 Esc 才关闭；非交互环境或保存失败显示具体原因，不报告成功，不破坏原配置。
- namespaced-entrypoints：命令为 /pi-company:setting，无法加载设置页时显示具体失败原因。

## 函数清单

### extensions/settings.ts
| 函数名 | 职责 |
|---|---|
| `settingsExtension` | 默认导出：注册 /pi-company:setting 命令；非终端模式提示"需要交互终端"并返回 |
| `openSettingsPage` | 用宿主的自定义组件接口（非浮层）替换输入栏，创建控制器会话，直到主页 Esc 才结束 |
| `renderMainPage` | 按控制器行模型渲染主页：蓝线、标题、范围行、角色标签、三字段、提示；应用限宽、空白压缩与选中蓝底 |
| `renderCandidatePage` | 渲染模型/思考/MCP 候选页：标题、可选搜索行、列表（含勾选标记与不可用标注）、提示 |
| `handleInput` | 把按键交给控制器，根据返回的视图状态切换主页或候选页，保存回执以通知显示 |
| `layoutMetrics` | 由终端宽高计算内容宽度、可用行数与是否压缩空白 |

## 协作关系
- 状态与行为全部来自 `runtime/settings-ui.ts`；模型上下文来自宿主模型注册表与当前会话模型、思考等级；MCP 候选来自 `runtime/mcp.ts` 的窗口探测。
- 组件只使用 pi-tui 的文本宽度工具与主题的前景/背景着色接口。

## 验证方式
- 测试入口：`extensions/settings.ts` 默认导出（假宿主收集命令与自定义组件工厂）；用 `renderComponent` 在 100×40 与 60×12 两种终端尺寸渲染
- 测试输入：三层角色目录、两层配置、假模型上下文、假 MCP 服务清单；按键序列
- 预期结果：
  - 100×40：首行与末行为全宽蓝线；主页行序为标题、范围行、空行、角色标签行、空行、"模型 - 来源"标题、缩进两格模型值、空行、"思考 - 来源"标题、缩进两格思考值、空行、"MCP - 来源"标题、缩进两格已勾选列表（无勾选为"无"、不可用项标注）、空行、一行完整提示；内容行宽度不超过 72 列
  - 60×12：蓝线仍等于 60 列；区块间空行被压缩后操作提示仍可见；无行超过 60 列
  - 在 MCP 字段按 Enter：标题为"worker MCP 选择"，无搜索行，Space 后勾选标记变化，Esc 回到主页且选中仍在 worker 的 MCP 字段；主页 Esc 才结束组件
  - 视图切换期间自定义组件工厂只被调用一次
  - 非终端模式调用命令：通知含"需要交互终端"，未创建组件
  - 保存目标不可写时通知含失败原因，主页显示原值
