# 面板活动模型

## 目标
面板只需消费一个纯数据模型即可渲染工作区内全部需求代理与子角色的真实状态。

## 业务规则（来源：spec）
- cross-window-panel：条目为"仓库 · 需求标题"及其子角色缩进行，显示状态、真实活动、轮次、耗时与待答标记，不显示任务文件路径，不显示工作区外仓库。
- cross-window-panel：活动来自守护进程推送的实际工具开始与结束事件；守护进程不可达时显示不可达，不用旧活动冒充。
- cross-window-panel：结束或用户停止的条目转灰色静态摘要并保留 20 秒后移出；临时操作失败提示显示 20 秒后恢复；两者自首次出现起计时，重绘与选择不续时，新提示替换并重新计时；暂停、中断与停止不确定不启动移除计时。
- 编辑文件数按不同文件计数，不把调用次数或上下文占用冒充完成度。

## 函数清单
### runtime/agents-activity.ts
| 函数名 | 职责 |
|---|---|
| `AgentsActivity` | 保存全部仓库的运行树与计时状态，暴露只读投影 |
| `AgentsActivity.applyRunsChanged` | 按 `runs.changed` 事件增删改需求代理与角色节点（状态、需求标题、仓库、待答标记） |
| `AgentsActivity.applyActivity` | 按工具开始/结束、轮次事件更新节点活动、轮次、编辑文件集合 |
| `AgentsActivity.markUnreachable` | 把某仓库全部节点标为不可达并附原因，清除活动动画 |
| `AgentsActivity.markReachable` | 恢复可达并等待新事件 |
| `AgentsActivity.transientError` | 记录一条 20 秒临时错误，新错误替换并重新计时 |
| `AgentsActivity.rows` | 生成有序面板行：仓库·需求首行 + 子角色缩进行，附耗时（扣除睡眠）、可用按钮集合 |
| `AgentsActivity.prune` | 按首次结束时刻移除超过 20 秒的结束条目；暂停、中断、不确定不移除 |
| `RETENTION_MS` | 常量 20000 |
| `buttonsFor` | 按状态给出按钮：运行中暂停/停止/查看，已暂停继续/停止/查看，中断续接/停止/查看，等待答复停止/查看 |

## 协作关系
- 输入来自 `runtime/daemon-client.ts` 的事件（`runs.changed`、`activity`）与状态（`unreachable`）；计时用 `runtime/clock.ts`。
- 输出供 `runtime/agents-panel.ts` 渲染；不含任何 TUI 依赖。

## 验证方式
- 测试入口：`AgentsActivity`（注入可控时钟）。
- 测试输入：两个仓库的运行变化事件；读取、搜索、对同一文件两次编辑的工具事件；结束、失败、用户停止、暂停、中断、不确定各一条；不可达标记；两次相隔 5 秒的临时错误；注入睡眠间隔。
- 预期结果：
  - 行顺序为仓库·需求首行后紧跟其角色缩进行；工作区外仓库不出现；行内无文件路径。
  - 两次编辑同一文件计文件数 1；工具结束后不再显示执行中。
  - 结束/失败/停止条目在 19 秒仍在、20 秒移出；暂停、中断、不确定 60 秒后仍在。
  - 第二次错误自其出现起重新计 20 秒，重绘与选择调用不改变计时。
  - 不可达后行显示不可达与原因，活动为空；耗时扣除注入的睡眠间隔。
  - 各状态按钮集合与规则一致。
