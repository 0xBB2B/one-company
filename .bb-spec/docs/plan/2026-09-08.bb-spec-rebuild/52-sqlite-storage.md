# SQLite 统一存储

## 目标与边界

用户已确认 pi-company 自有业务与审计数据使用 SQLite 读写，每条记录使用 UUIDv7 主键。业务与审计数据包括仓库登记、需求与任务运行状态、运行记录、决策、中继、窗口、范围占用、设置、会话、结构化失败详情、Shell 登记和迁移进度。普通运行日志使用 .log 文件。源码、规则与任务定义、验收报告是 Git 交付文件；外部 SDK 与 MCP 提供的配置仍由其提供方管理，只读取。Unix socket 和命令临时工作目录是操作系统资源，不作为应用数据源。

同仓库各 worktree 使用同一个仓库数据库，全局设置使用本机全局数据库；不跨数据库执行事务。数据库目录权限 0700，数据库文件权限 0600，数据库及 WAL 不允许模型文件工具或命令直接访问。

## 数据与事务约束

- 所有业务表均以 UUIDv7 文本列为主键，并在数据库约束及入口校验中检查格式；仓库指纹、需求名称、任务编号、决策显示编号、SDK 条目编号作为业务标识，不代替主键。
- 精确顺序使用流内事务序号；UUID 时间部分不承担时钟、超时或全局因果顺序。
- 开启 WAL、外键、同步落盘与有界忙等待；迁移版本使用 SQLite user_version。
- 状态变更必须携带已读版本，用条件更新检查版本；过期操作拒绝，不能以整文档覆盖掩盖冲突。
- 编号分配与追加、首次作答、送达回执、占用检查与登记分别在短事务内完成。
- 不在数据库写事务中等待模型、Shell、Git、网络或用户；外部核验在事务外执行，写入前重新检查版本与相关身份。
- SDK 会话使用其内存会话接口，条目由 SQLite 持久化并在恢复时回填；不创建第二份可写会话文件。
- 数据库失败不伪报成功，不回退至 JSON。删除被替代的文件锁、JSON/JSONL 写入和目录扫描分支。
- 显式迁移入口处理仓库 `.pi-spec` 中的旧运行字段与决策；校验并写入 SQLite 后清理旧运行字段，将定义目录改名为 `.pi-company`。不引入第二套本机文件存储读取入口。

## 实现与验收

1. SQLite 基础层与 UUIDv7：Node 实际宿主和 Bun 测试运行时均可使用；主键、唯一约束、版本冲突、并发追加、事务回滚、强杀恢复验证通过。
2. 运行与工作流：完整创建可见、合法状态转换、需求单实例、交付和失效证据、持久化等待任务。
3. 决策与中继：多进程编号唯一、首答唯一、回执不互相覆盖、离线顺序与重启恢复。
4. 占用与窗口：冲突检查与登记原子，心跳不复活注销窗口，外部存活核验不占写事务。
5. 设置、会话、结构化失败详情、Shell 登记与迁移：公开入口全部读写 SQLite，重启后查询与续接成立，数据库不可用时明确失败。
6. 规范、计划、README、测试夹具和诊断入口统一；全量测试、严格类型检查与真实 SDK 扩展装载通过。

## 完成条件

生产代码中不存在绕过 SQLite 的 pi-company 业务与审计记录写入；所有业务表主键均符合 UUIDv7；旧文件链路已删除；完整工作流及保护反例有真实执行证据。

## 安全性、鲁棒性与简洁性复核

- SQLite 解决持久化原子性；WAL 允许读写并行，但每库同时只有一个写事务。短事务、有界忙等待和版本比较共同防止竞争覆盖，外部核验仍在事务外进行。
- UUIDv7 只承担主键身份。业务唯一键和流内序号分别约束重复记录与严格顺序，不用主键排序推断业务先后。
- 排队派工保存原始说明与等待条件；正式启动重新采集版本，重复续接串行检查。取消、父运行未恢复、坏依赖都不能启动任务。
- Shell 在隔离准备后再次核对取消；登记期间发生取消时，登记返回后停止进程，前台与后台路径一致。
- 模型消息按运行串行提交，等待 SDK 请求完整收尾，避免同时预处理或回合结束回调触发重复请求；暂停和恢复保持排队消息。
- 会话条目与当前分支位置同事务更新，写入失败停止会话；旧写入者不能覆盖新上下文。阶段和证据同事务提交，迟到绑定不能覆盖失效。
- 命令通过 macOS 文件隔离执行，获准仓库内命令与 linked worktree 提交可用，跨仓读写及本机数据库访问拒绝；认证环境变量不传给命令。其他平台缺少隔离后端时拒绝命令执行。
- 验收报告位置由需求身份推导，调用方无需重复传参；显式路径必须与推导结果一致。保留任务定义中的生产文件与正文测试文件的不同用途，核验覆盖两者。
- 删除被替代的目录定位函数、目录锁和 JSON/JSONL 写入 API，列表一次读取数据库快照，安全检查不按展示页大小截断。

## 启动诊断核验

- 普通运行日志写入仓库数据目录的 logs/<启动 UUIDv7>.log，每实例独立追加且权限为 0600，客户端只读取本次日志末尾最多 4096 字节。
- 标准输出与标准错误使用子进程继承的文件描述符，不连接派出窗口管道；窗口退出后继续写入。删除 SQLite 日志写入、读取及标准错误拦截模块。
- 已选 MCP 服务不可用时仅从实际开放集合移除，配置保持；不依赖该服务的任务仍可启动，能力缺失不得被当作验收通过。
