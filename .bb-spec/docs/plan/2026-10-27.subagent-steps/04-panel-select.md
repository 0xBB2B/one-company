# 面板里选中子代理

## 目标
状态面板获得焦点后，↑↓ 能停在正在运行的子代理行上，按回车打开它的步骤窗口；面板每一行的文字不变。

## 业务规则（来源：PRD select-subagent）
- 能停的行按屏幕从上到下：需求行；有任务行时，按任务逐个列出这个任务的 ⚑ 事项行、执行行、运行中的审查代理行，所有任务之后是 PM 派出的"explore 检索"行，再后是不属于任务的 ⚑ 事项行（和 `taskLines` 画的顺序一致）；没有任务行时是需求行后面的 ⚑ 事项行（现有顺序）；然后是面板底部的原型设计行、检索行。
- 跳过：审查标题行（"T1 第 1 轮审查"）、"●"开头的分组标题行、状态不是 running 的审查代理行（通过、打回、等重派、用满、已关闭、已不存在）。
- 选中的子代理行用和需求行一样的高亮（主题有 `selectedBg` 背景时用背景，没有时把行首字符换成"›"）。
- 回车：子代理行 → 打开它的步骤窗口；需求行 → 什么都不做；⚑ 事项行 → 插入决策包（不变）。
- p：需求下面的子代理行 → 暂停或恢复所属需求的 PM（同需求行）；原型设计行、检索行 → 什么都不发生（按键被面板吃掉，不发请求）。
- 只要有一行能选，输入框为空、没有补全菜单和弹窗时按 ↓ 就进面板，包括只有原型设计或检索行时。
- 刷新后选中的子代理行（按运行编号认）还在就停在它上面，不在了落到相邻行。关掉步骤窗口回到面板，光标还在原来那一行。
- 每一行的文字、底部提示"↑↓ 选择 · Enter 查看 · p 暂停/恢复 · Esc 返回输入框"都不变。
- 步骤窗口标题：执行行 `<任务号> 执行 · <代理>（第 <n> 次尝试）`；审查代理行 `<任务号> 第 <轮> 轮审查 · <代理>`；PM 派出的检索 `explore 检索`；原型设计 `<名称>（第 <版本> 版）· <代理>`；主窗口检索 `<本地|联网> · <问题>`（问题里的连续空白合成一个空格）。

## 涉及文件
- 修改 `src/modules/panel/pm-panel.ts`
- 修改 `src/modules/panel/pm-panel-extension.ts`

## 函数清单
### src/modules/panel/pm-panel.ts
| 函数名 | 职责 |
|---|---|
| `PmPanelOptions.openSteps`（新选项） | 用户在子代理行按回车时调用，带仓库编号、运行编号和窗口标题 |
| `Row`（类型） | 增加子代理行：所属需求（主窗口的原型设计和检索没有）、仓库编号、运行编号、窗口标题 |
| `PmPanel.rows` | 按上面的顺序列出所有能停的行 |
| `PmPanel.hasRows` | 有任何一行能停就为真 |
| `PmPanel.handleInput` | 回车和 p 按行类型分流 |
| `PmPanel.taskLines` / `reviewerLine` / `render` | 子代理行被选中时加高亮，文字不变 |
| `rowKey` | 子代理行按运行编号认 |
| `subagentTitle`（新，模块内） | 按上面的规则拼窗口标题 |

### src/modules/panel/pm-panel-extension.ts
| 函数名 | 职责 |
|---|---|
| `pmPanelExtension` 里挂面板的地方 | 提供 `openSteps`：找到该仓库的守护进程客户端，调用 `openStepWindow`（03 计划），传入 ctx、本扩展的 `dock`、clock、运行编号、标题和主题；找不到客户端时提示"找不到该仓库的守护进程连接"（同现有 openItem） |

## 协作关系
- 子代理行的运行编号来自概览行的 `runId`（02 计划）和 `MainExploreOverview.runId`、`MainPrototypeOverview.runId`（现有）。
- 底部区块 `BottomDock` 进面板的判断调用 `panel.hasRows()`，改了 `hasRows` 后只有原型设计或检索行时也能进面板；打开步骤窗口期间 `markPageOpen` 让底部区块不处理按键，关闭后 `markPageClosed` 把焦点还给面板。

## 验证方式
- 测试入口：`PmPanel`（按 `tests/pm-panel.test.ts` 构造面板和概览数据，调 `focus`、`handleInput`、`render`）；`BottomDock`（按 `tests/bottom-dock.test.ts`）；`pmPanelExtension`（假守护进程客户端）。
- 测试输入：一个需求，任务行为 T2 执行（运行中）、T1 审查轮（reviewer 运行中、go-reviewer 通过、另一个打回）、PM 派出的检索；一个原型设计；一个主窗口检索。
- 预期结果：
- [ ] 进面板后光标在需求行，连按 ↓ 依次停在 T2 执行、reviewer、PM 检索、原型设计、主窗口检索，到底后不动；连按 ↑ 回到需求行；通过和打回的审查代理行、审查标题行停不上去。
- [ ] 光标在 T2 执行行时这一行带选中背景，其他行不带。
- [ ] 在 T2 执行、reviewer、PM 检索、原型设计、主窗口检索行按回车，`openSteps` 依次收到对应运行编号和标题："T2 执行 · worker（第 1 次尝试）"、"T1 第 1 轮审查 · reviewer"、"explore 检索"、"导出设置页（第 1 版）· prototype"、"本地 · 现在的导出入口在哪"；需求行回车不调用任何回调；⚑ 行回车照旧调用 `openItem`。
- [ ] T2 执行行按 p 调用 `togglePause`（参数是所属需求）；原型设计行、检索行按 p 不调用任何回调，但按键被吃掉。
- [ ] 只有一个主窗口检索时 `hasRows()` 为真，底部区块按 ↓ 进入面板；什么都没有时为假。
- [ ] 选中 T2 执行行后用含 T2（同运行编号）的数据刷新，光标不动；用不含 T2 的数据刷新，光标落到相邻行。
- [ ] 同一份数据，改动前后 `render` 去掉高亮后的每一行文字一样。
- [ ] 扩展层：`openSteps` 被调用时用该仓库客户端打开步骤窗口；客户端不存在时提示"找不到该仓库的守护进程连接"。
