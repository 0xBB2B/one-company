# 角色定义栏调整

角色定义栏：/one:agents 分类栏左边按职责分的几栏，列出内置、用户、项目三层生效的角色定义。

## 用户故事
### P1：作为想加一个前端工程师的用户，我想要复制出来的文件一看就知道能填什么
**用例（主路径）**
- 场景：用户想做一个 vue-engineer。
- 操作：打开 /one:agents，在 worker 栏选中内置 worker，按 C，输入 vue-engineer，选用户层。
- 预期：生成的文件里有名称、描述、职责，还有空的 skills 和空的 mcp，不写模型和思考等级（不写就跟随主窗口）；正文为空；列表里 vue-engineer 的名字变绿，底部提示"打开它写专长、skills 和 mcp"。

### P1：作为查看定义的用户，我想要知道正文为空是正常的
**用例（主路径）**
- 场景：用户展开内置 worker 的详情。
- 操作：选中 worker 按回车。
- 预期：详情里有一行"正文：空 · 流程规矩由程序加上，正文只写专长和偏好"。

## 约束
- C-1：分类栏左边只有 worker、reviewer、qa、explore 四栏，右边是设定栏，有问题时再加问题栏；不再有 pm 栏和内部栏。右上角的计数只算这四个职责的定义。
- C-2：任何一栏里的定义按 C 都能复制成新名字，名字规则不变：小写字母、数字、连字符，最多 64 个字符，三层里不能重名。不再有"只能同名复制"。
- C-3：内置的 worker、reviewer、qa、explore 定义里写有空的 skills 和空的 mcp，不写模型和思考等级，派出时跟随主窗口当时的模型和思考等级；复制出来的文件照源文件的头部，同样带 skills 和 mcp。
- C-6：表格里没写模型的定义，模型列写"跟随主会话"；没写思考等级的，思考列写"跟随"。
- C-4：展开详情时显示「正文」一行：正文为空时写"空 · 流程规矩由程序加上，正文只写专长和偏好"，写了正文时写"已写 · 流程规矩由程序加上，优先于正文"。
- C-5：页面不显示工具；定义里写工具字段，仍按"不认识的字段"处理。

## 验收
### AC-1 只有四个职责栏 ← C-1
- 触发：打开 /one:agents
- Given：没有写错的定义
- When：查看分类栏和右上角计数
- Then：左边依次是 worker、reviewer、qa、explore，右边是设定栏；没有 pm 栏和内部栏；内置计数是 4

### AC-2 任意定义可改名复制 ← C-2
- 触发：按 C
- Given：选中内置 explore
- When：输入 web-explore 并选用户层
- Then：用户层生成 web-explore；输入已存在的名字时提示换一个

### AC-3 文件自带 skills 和 mcp ← C-3
- 触发：查看内置定义文件和复制出的文件
- Given：刚复制出 vue-engineer
- When：读这两份文件
- Then：都写有空的 skills 和空的 mcp，都没有模型和思考等级两项，正文为空

### AC-4 详情显示正文状态 ← C-4
- 触发：回车展开详情
- Given：内置 worker 正文为空；vue-engineer 正文写了一句专长
- When：分别展开
- Then：前者显示"空 · 流程规矩由程序加上，正文只写专长和偏好"，后者显示"已写 · 流程规矩由程序加上，优先于正文"

### AC-5 不显示工具 ← C-5
- 触发：展开任意定义的详情
- Given：一份定义多写了工具字段
- When：查看页面
- Then：详情里没有工具；这份定义列进问题栏，原因是"不认识的字段"

### AC-6 跟随的写法 ← C-3、C-6
- 触发：打开 /one:agents 的 worker 栏
- Given：内置 worker 没写模型和思考等级；vue-engineer 写了 gpt-6.1-sol、high
- When：查看两行
- Then：worker 行模型列写"跟随主会话"、思考列写"跟随"；vue-engineer 行写 gpt-6.1-sol、high

## 验证路径
1. 打开 /one:agents → 只有四个职责栏和设定栏（AC-1）。
2. 复制 worker 为 vue-engineer → 读文件，展开详情（AC-2、AC-3、AC-4）。
3. 在文件里加一个工具字段 → 问题栏出现这份定义（AC-5）。
