# 点选回答带上选项理由

## 用户故事
### P0：作为用户，我想要主代理按我点选那一项的标题和理由改草稿，以便理由里已经定下的内容不被漏写

**用例（主路径）**
- 场景：主代理问"第一版 MCP 要支持哪些任务管理操作"，第 2 项标题"查询、承接或拒绝，再加手动排期和更新进度"，理由"支持查询需求列表和详情、承接或拒绝，手动设置计划交付日期、优先级及任务进度"，标为推荐。
- 操作：用户在窗口里点选第 2 项。
- 预期：ask 返回 `status=answered`，`answer.choice=2`，`answer.text` 为"查询、承接或拒绝，再加手动排期和更新进度"换行"支持查询需求列表和详情、承接或拒绝，手动设置计划交付日期、优先级及任务进度"，不带"选第 2 项："和"（推荐）"。

**用例（边界）**
- 操作：面板事项提问里，用户点选第 1 项"再给一次机会，轮数上限 3"，理由"任务只差最后一步"。
- 预期：`answer.text` 为"再给一次机会，轮数上限 3"换行"任务只差最后一步"，`answer.choice=1`，`decision` 照常返回。

**用例（边界）**
- 操作：用户选"其他"输入"7 分钟"。
- 预期：`answer.text` 为"7 分钟"，`answer.other=true`，和现在一样。

**用例（边界）**
- 操作：用户按 Esc 暂不回答。
- 预期：`status=pending`，`answer=null`，和现在一样。

## 约束
- C1：需求澄清提问里用户点选某一项时，返回的 `answer.text` 等于交给草稿核验器和解释器的用户原话，即"该项标题 + 换行 + 该项理由"；`answer.choice` 仍为所选序号。
- C2：面板事项提问里用户点选某一项时，`answer.text` 按 C1 同样取值，`answer.choice` 和 `decision` 照常返回。
- C3：用户选"其他"时，`answer.text` 是用户输入的原文，`answer.other=true`；暂不回答时 `answer=null`。
- C4：终端里提问结果的显示不变：点选时显示"你的回答  N. 标题（推荐）"，选"其他"时显示输入内容加"（自己输入）"。
- C5：主代理规则写明：`status=answered` 时 `answer.text` 就是用户这一轮的原话，按它改草稿。

## 验收
- [ ] C1：需求澄清提问点选第 2 项 → `answer.text` 与核验器收到的 `text` 字段完全相同，均为"标题\n理由"；`answer.choice=2`。
- [ ] C2：面板事项提问点选第 1 项 → `answer.text` 为"标题\n理由"，`answer.choice=1`，`decision` 含事项编号与版本。
- [ ] C3：选"其他"输入"7 分钟" → `answer.text="7 分钟"`、`answer.other=true`；暂不回答 → `answer=null`。
- [ ] C4：点选推荐项后终端显示"你的回答  2. 标题（推荐）"，不显示理由。
- [ ] C5：主代理规则文件的提问条目里写有"answer.text 就是用户这一轮的原话"。

## 验证路径
1. 需求澄清提问，用户点选带理由的推荐项 → 返回的 answer.text 是两行"标题、理由"。
2. 主代理按 answer.text 改草稿并提交 → 核验器收到的 text 与 answer.text 相同。
3. 终端里看提问结果 → 仍显示"你的回答  N. 标题（推荐）"。
4. 面板事项提问点选一项 → answer.text 同样是两行，decision 照常返回。
