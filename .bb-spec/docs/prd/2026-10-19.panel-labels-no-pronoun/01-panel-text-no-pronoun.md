# 面板文字去掉"你"

## 用户故事
### P0：作为用户，我想要状态面板上的事项文字不带"你"，以便主代理照抄事项标签发起提问时不被退回、直接弹出窗口

**用例（主路径）**
- 场景：需求"角色跳跃"的任务 login 两次没完成，PM 把它交给用户裁决。
- 操作：用户看状态面板，按 ↑↓ 选中这个事项后按 Enter；主代理读完决策包，用 `one_company_user_interact` purpose=panel-item 提问，问题写"待裁决：任务 login 两次未完成，怎么处理？"。
- 预期：面板第二行是"等待决定"，事项行是"⚑ 待裁决：任务 login 两次未完成"；决策包第一行是"[待处理事项] 待裁决：任务 login 两次未完成"；提问窗口正常弹出，标题是"待裁决：任务 login 两次未完成"。

**用例（边界：PM 上报）**
- 场景：PM 对还没派出的任务 font 上报，需要用户决定。
- 预期：事项行是"⚑ 待裁决：任务 font PM 上报需要决定"。

**用例（边界：任务终止后需求暂停）**
- 场景：用户终止了任务 login，需求整体暂停。
- 预期：第二行是"等待调整需求"，事项行是"⚑ 待决定：任务 login 已终止，请调整需求或取消需求"。

## 约束
- C1：7 种事项标签按下表输出（任务名、版本号按实际值替换）：

  | 事项 | 标签 |
  |---|---|
  | 任务终止，待调整或取消需求 | `待决定：任务 <任务名> 已终止，请调整需求或取消需求` |
  | 任务待裁决 | `待裁决：任务 <任务名> <原因>` |
  | 核对 PM 接手理解 | `待核对：PM 接手理解 r<版本>` |
  | 任务的未决问题 | `待回答：任务 <任务名> 的未决问题` |
  | PM 完成报告 | `待验收：PM 完成报告` |
  | PM 计划两次被拒 | `待裁决：PM 计划两次提交被拒` |
  | PM 停下 | `待处理：PM 停下了，没有在跑的子任务` |

  任务待裁决的原因里，"两次未完成""两次审查未完成""两次未通过审查"和拆分上限原文不变。
- C2：PM 上报或任务带待定说明时，任务待裁决的原因是"PM 上报需要决定"。
- C3：面板第二行的 4 处状态文字：任务终止后暂停时为"等待调整需求"；计划提交被拒 2 次及以上时为"规划中（计划提交被拒 N 次，等待决定）"；等待且有完成报告事项时为"等待验收完成报告"；等待且有其他事项（PM 停下除外）时为"等待决定"。
- C4：决策包第一行"[待处理事项] "后面、面板事项提问窗口的标题，用的都是 C1、C2 的新标签。
- C5：主代理用 purpose=panel-item 提问，问题含 C1、C2 的任一新标签原文，其余文字不含"我""你""您" → 窗口正常弹出，不被退回。
- C6：主代理规则文件里提到这些事项时用"待裁决""待验收"，不再出现"待你裁决""待你验收"。

## 验收
- [ ] C1：分别构造 7 种事项 → 标签与上表逐字相同，且都不含"你"。
- [ ] C2：PM 上报的任务 → 标签为"待裁决：任务 <任务名> PM 上报需要决定"。
- [ ] C3：分别构造 4 种状态 → 第二行文字与 C3 逐字相同，且不含"你"。
- [ ] C4：选中"待裁决"事项 → 决策包第一行为"[待处理事项] 待裁决：任务 <任务名> <原因>"；对它发起面板事项提问 → 窗口标题为同一标签。
- [ ] C5：问题写"待裁决：任务 login 两次未完成，怎么处理？"的面板事项提问 → ask 返回 answered 或 pending，没有 question_format 错误。
- [ ] C6：主代理规则文件里有"待裁决""待验收"，没有"待你裁决""待你验收"。

## 验证路径
1. 构造一个任务两次没完成的需求 → 面板显示"等待决定"和"⚑ 待裁决：任务 login 两次未完成"。
2. 选中事项 → 决策包第一行是"[待处理事项] 待裁决：任务 login 两次未完成"。
3. 主代理照抄标签写问题发起面板事项提问 → 窗口弹出，标题是同一标签。
4. 依次构造终止、核对、未决问题、完成报告、计划两次被拒、PM 停下、PM 上报 → 每个标签和第二行文字都与约束一致、不含"你"。
