# 右栏按 Esc 回到目录

设置页：输入 /one:setting 打开的页面。目录：设置页左边那一栏，列出 worker、reviewer、qa、explore、prototype、模型、开关等分类，有写错的文件时还有「问题」。右栏：设置页右边那一栏，显示目录里选中分类的内容。焦点：现在按键作用在哪一栏，在目录时按 → 或回车进入右栏。分步修改：在「模型」或「开关」的一行上按回车后，在右栏里一步步选择新值和存到哪一层的画面。复制起名：在一份角色定义上按 C 后，输入新定义名字的画面。窄屏：终端不到 60 列时，目录和右栏轮流占满整个宽度。

## 用户故事
### P0：作为在设置页里浏览的用户，我想要在右栏按 Esc 回到目录，以便接着看别的分类而不用重新打开设置页

**用例（主路径）**
- 场景：用户在 80 列终端里想先看 PM 的模型，再去看 worker 的定义。
- 操作：输入 /one:setting，↓ 到「模型」，按 →，看完按 Esc。
- 预期：设置页没有关闭；焦点回到目录，目录光标还在「模型」并带选中底色；按键提示是"↑↓ 选分类  → 进右栏  Esc 退出"。接着按 ↑ 能换到别的分类。

**用例（边界：详情展开时）**
- 场景：用户在 worker 分类里展开了一份定义的详情。
- 操作：按 → 进入右栏，按回车展开，再按 Esc。
- 预期：焦点回到目录，目录光标还在 worker；再按 → 进入右栏，这份定义的详情是收起的。

**用例（边界：窄屏）**
- 场景：用户的终端只有 44 列。
- 操作：输入 /one:setting，↓ 到「模型」，按 →，再按 Esc，再按 Esc。
- 预期：按 → 后只显示模型列表，按键提示以"←/Esc 回目录"开头；第一次按 Esc 后只显示目录；第二次按 Esc 后设置页关闭。

**用例（边界：正在分步修改）**
- 场景：用户在「模型」里改 PM 的模型，走到了第 2 步选思考等级。
- 操作：按 Esc，再按 Esc，再按 Esc。
- 预期：第一次 Esc 退回第 1 步选模型；第二次 Esc 取消修改，回到模型列表，焦点仍在右栏，底部写"已取消修改"；第三次 Esc 焦点回到目录，设置页没有关闭。

## 约束
- C-1：焦点在右栏，并且没有在分步修改或复制起名时，按 Esc 和按 ← 效果完全一样：焦点回到目录，目录光标停在原来的分类，右栏展开的详情收起，设置页不关闭。
- C-2：焦点在目录时按 Esc，设置页关闭。
- C-3：分步修改和复制起名里按 Esc，行为和改动前一样：分步修改退回上一步，第一步按 Esc 取消修改，底部写"已取消修改"；复制起名按 Esc 取消，底部写"已取消复制"。两种情况取消后焦点都留在右栏，设置页不关闭。
- C-4：终端 60 列及以上时，按键提示按焦点和分类变化：
  - 焦点在目录："↑↓ 选分类  → 进右栏  Esc 退出"
  - 右栏在职责分类（worker、reviewer、qa、explore、prototype）："←/Esc 回左栏  ↑↓ 选择  回车 详情  C 复制"；选中行展开后，"回车 详情"改成"回车 收起"
  - 右栏在模型或开关："←/Esc 回左栏  ↑↓ 选择  回车 修改  R 清除本层"
  - 右栏在问题："←/Esc 回左栏  ↑↓ 选择  回车 详情"；展开后改成"回车 收起"
- C-5：终端不到 60 列时，按键提示在 C-4 的基础上改两处："→ 进右栏"改成"→ 进入"，"←/Esc 回左栏"改成"←/Esc 回目录"。窄屏里 Esc 的行为和 C-1、C-2 一样：右栏按 Esc 回到只显示目录的画面，目录里按 Esc 关闭设置页。

## 验收
- [ ] AC-1 ← C-1：80 列打开设置页，↓ 到「模型」，按 → 再按 Esc：设置页没有关闭，目录里「模型」那一行带选中底色，按键提示是"↑↓ 选分类  → 进右栏  Esc 退出"。
- [ ] AC-2 ← C-1：在 worker 分类按 →、回车展开一份定义，再按 Esc，然后按 →：右栏里这份定义是收起的，光标符号是 ▸。
- [ ] AC-3 ← C-2：打开设置页直接按 Esc，设置页关闭；从右栏出发连按两次 Esc，设置页关闭。
- [ ] AC-4 ← C-3：在「模型」里对 PM 按回车走到第 2 步，连按两次 Esc：回到模型列表，焦点在右栏，底部写"已取消修改"，设置页没有关闭，两层设置文件都没变；再按 Esc，焦点回到目录，设置页没有关闭。
- [ ] AC-5 ← C-3：在 worker 的一份定义上按 C，再按 Esc：回到列表，焦点在右栏，底部写"已取消复制"，设置页没有关闭，没有生成文件。
- [ ] AC-6 ← C-4：80 列下，在目录、职责分类、职责分类展开后、模型、开关、问题、问题展开后，各自的按键提示与 C-4 一致；右栏的按键提示里都没有"Esc 退出"。
- [ ] AC-7 ← C-5：44 列下，目录的按键提示是"↑↓ 选分类  → 进入  Esc 退出"；进入「模型」后按键提示以"←/Esc 回目录"开头；按 Esc 回到只显示目录的画面；再按 Esc 设置页关闭。

## 验证路径
1. 80 列打开 /one:setting → ↓ 到「模型」→ → → Esc → 看焦点和按键提示（AC-1、AC-6）→ 再按 Esc，页面关闭（AC-3）。
2. 重开 → worker 里 → 回车展开 → Esc → → → 看详情是否收起（AC-2）。
3. 「模型」里对 PM 回车 → 回车 → Esc → Esc → Esc（AC-4）；worker 里按 C → Esc（AC-5）。
4. 依次进入职责分类、模型、开关、问题，展开和收起，对照按键提示（AC-6）。
5. 把终端调到 44 列，重复第 1 步（AC-7）。
