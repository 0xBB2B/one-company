# 设置页右栏按 Esc 回到目录

设置页：输入 /one:setting 打开的页面。目录：设置页左边那一栏，列出所有分类。右栏：设置页右边那一栏，显示目录里选中分类的内容。焦点：现在按键作用在哪一栏。

## 背景与问题
用户在设置页里按 → 或回车进入右栏，查看定义详情或模型设定，看完想回到目录换一个分类。很多终端程序都用 Esc 表示"退回上一层"，用户顺手按了 Esc，结果整个设置页直接关闭，只能重新输入 /one:setting，再从头找到刚才的分类。现在回到目录只能按 ←。

## 目标
- 焦点在右栏、没有在分步修改或给复制的定义起名时，按 Esc 回到目录，效果和按 ← 一样。
- 焦点在目录时按 Esc 关闭设置页。从右栏出发，连按两次 Esc 就能关闭页面。
- 按键提示如实写出 Esc 在当前画面的作用。

## 非目标
- 分步修改（模型、思考等级、存到哪一层；Git 交付的两步）和复制起名里的 Esc 行为不动：分步修改按 Esc 退回上一步，第一步按 Esc 取消；复制起名按 Esc 取消复制。
- 不加"右栏里一按就关闭整页"的其他快捷键。
- ← 和 → 的行为不动。

单一子需求，无依赖。

## 整体验证路径
1. 80 列终端输入 /one:setting，↓ 到「模型」，按 → 进入右栏 → 按键提示是"←/Esc 回左栏  ↑↓ 选择  回车 修改  R 清除本层"。
2. 按 Esc → 焦点回到目录，光标还在「模型」，设置页没有关闭，按键提示是"↑↓ 选分类  → 进右栏  Esc 退出"。
3. 再按 Esc → 设置页关闭。
4. 44 列终端重复第 1 到 3 步 → 右栏的按键提示里写"←/Esc 回目录"，按 Esc 回到目录，再按 Esc 关闭。

## 决策记录
- 右栏里 Esc 的作用和 ← 完全一样：回到目录，同时收起展开的详情。理由：用户要的就是"退回上一层"，← 已经是这个行为，照搬它不用另外定义一套规则。
- 否决"右栏里连按两次 Esc 才关闭页面"：效果和"先回目录、在目录再按 Esc 关闭"一样，还要多一套计时或计数逻辑。
- 按键提示把 ← 和 Esc 合成一组，写成"←/Esc 回左栏"（窄屏写"←/Esc 回目录"），并从右栏的提示里去掉"Esc 退出"，因为在右栏按 Esc 已经关不掉页面。用户 2026-10-19 决定。
- 这次改的是 2026-10-16 设置页上线时定下的"任何时候按 Esc 都关闭设置页"，当时的记录里没有写选这个行为的理由。用户 2026-10-19 决定改掉。
