# 输入栏多行编辑

几个词先说清楚：
- 程序窗口：程序弹出、请用户亲手选择的窗口，例如确认原型、主代理提问、面板事项提问（含验收）、项目规范更新。
- 输入行：程序窗口里可以自己输入文字的那一行选项，例如"其他（自己输入）""通过并补充说明（自己输入）""其他（自己输入修改意见）"。
- 输入栏：输入行下面显示已输入文字、接收按键的那块区域。
- 全屏模式：pi 自己接管整个终端屏幕的显示模式，只有这时鼠标点击会交给程序；另一种是普通模式，鼠标由终端负责选中复制和滚动。

## 用户故事
### P0：作为用户，我想要写长意见时能分段、能改中间的字
**用例（主路径）**
- 场景：确认原型窗口弹出，用户要写一段较长的补充说明。
- 操作：光标移到"通过并补充说明（自己输入）"，输入"用 B 方案（顶部分栏），A 和 C 不要。"，按 Shift+Enter，输入"顶部分栏里的标签按使用频率排序"；按 ← 四次，输入"常用"；回车。
- 预期：输入栏显示两行，第二行是"顶部分栏里的标签按常用使用频率排序"；登记的补充说明是这两行原文（中间有换行）。

**用例（长输入）**
- 场景：80 列终端，主代理提问窗口。
- 操作：光标移到"其他（自己输入）"，连续输入 100 个汉字。
- 预期：文字在终端宽度内折成多行，第一行以"›"开头，续行和第一行文字左对齐；pi 没有退出。

### P0：作为用户，我想要粘贴大段文字时窗口不被撑满
**用例（主路径）**
- 场景：用户要把一份 42 行的设计规范贴进确认原型窗口的"其他"一行。
- 操作：输入"按下面这份设计规范再核对一遍："，再粘贴 42 行文字，回车。
- 预期：输入栏显示"按下面这份设计规范再核对一遍：[paste #1 +42 lines]"；主代理收到的原话是完整的 42 行。

### P1：作为全屏模式下的用户，我想要点哪里光标就到哪里
**用例（主路径）**
- 场景：pi 在全屏模式，输入栏里已有两行字。
- 操作：用鼠标点击第一行的第 5 个字。
- 预期：光标移到第 5 个字前面，接着输入的字插在那里。

## 约束
- C-1：本子需求适用于所有程序窗口的输入行：确认原型窗口的"通过并补充说明""其他"，主代理提问窗口和面板事项提问窗口（含验收）的"其他"，项目规范更新窗口的"其他（自己输入修改意见）"。
- C-2：输入栏显示在输入行下面：第一行以"      › "（6 个空格、›、1 个空格）开头，其余各行以 8 个空格开头，文字左对齐；长文字在终端宽度内自动折行，用户插入的换行另起一行。终端宽 36、44、60、80 列时，无论输入多少字、多少行，窗口画出的每一行都不超过终端宽度。
- C-3：光标在输入行上时，输入栏在光标位置显示反色光标块；光标不在输入行上时，有字就照样显示文字、没有光标块，没有字就不显示输入栏。每个输入行的文字和光标位置各自保留，光标移走再回来时回到原处。
- C-4：光标在输入行上时：可见字符插入在光标处；Backspace 删光标前一个字，Delete 删光标后一个字；← → 按字移动（可跨行）；Home、End 移到当前行的开头、末尾；Shift+Enter 和 Ctrl+J 在光标处插入换行；回车提交。
- C-5：光标在输入行上时，↑ ↓ 在输入栏的显示行之间移动；光标已在输入栏第一行时按 ↑，光标移到上一个选项；已在最后一行时按 ↓，移到下一个选项（没有下一个选项时不动）。从别的选项移进输入行时，输入栏回到上次离开时的光标位置。
- C-6：回车时，去掉首尾空白后为空、或超过这一行的字数上限，回车不起作用、窗口不关；否则提交去掉首尾空白后的文字，中间的换行保留。
- C-7：字数按完整原文计算（粘贴折叠的部分按原文算，换行算 1 个字）；超过上限时，输入栏最后一行下面显示灰字"超出 N 字，最多 M 字"。
- C-8：一次粘贴超过 10 行或超过 1000 字时，输入栏里显示为一个标记：多行时"[paste #<序号> +<行数> lines]"，单行时"[paste #<序号> <字数> chars]"，序号在同一个输入栏里从 1 开始递增；提交时标记换回完整原文。没超过的粘贴原样插入，保留换行。
- C-9：光标在输入行上时，底部提示是"直接输入 · 回车确认 · Shift+Enter 换行 · ↑↓ 选择 · <这个窗口原有的 Esc 那一段>"；不在输入行时底部提示保持现状。
- C-10：按 Esc 时，各窗口按原有含义处理（例如确认原型窗口登记放弃、提问窗口暂不回答），不论输入栏里有没有字。
- C-11：pi 在全屏模式时，用户点击某个输入栏的文字区域，光标移到那个输入行，并定位到点击的字的前面；点击输入栏最后一个字后面的空白处，光标到那一行末尾。pi 在普通模式时，点击不改变窗口状态。

## 验收
### AC-1 适用的窗口 ← C-1
- 触发：分别打开确认原型窗口、主代理提问窗口、验收窗口、项目规范更新窗口
- Given：每个窗口的输入行
- When：在输入行上按 Shift+Enter 再输入"乙"
- Then：四个窗口的输入栏都变成两行，第二行是"乙"

### AC-2 折行与宽度 ← C-2
- 触发：在输入行上输入文字
- Given：终端宽 36、44、60、80 列
- When：输入 100 个汉字；再按 Shift+Enter 输入 50 个英文字母
- Then：每种宽度下窗口每一行的显示宽度都不超过终端宽度；输入栏第一行以"      › "开头，其余行以 8 个空格开头；字母另起一行

### AC-3 光标块与各自保留 ← C-3
- 触发：在两个输入行之间切换
- Given：确认原型窗口
- When：在"通过并补充说明"输入"甲乙丙"，按 ← 一次；↓ 移到"其他"输入"丁"；↑ 回到"通过并补充说明"
- Then：离开时"通过并补充说明"下面仍显示"甲乙丙"、没有光标块；回来后光标块在"丙"上；"其他"下面仍显示"丁"

### AC-4 编辑按键 ← C-4
- 触发：在输入行上按键
- Given：输入栏是空的
- When：输入"abc"，← 一次，输入"X"，Home，输入"Y"，End，Backspace，Delete（在末尾），Shift+Enter，输入"d"，Ctrl+J，输入"e"，回车
- Then：提交的文字是"YabX\nd\ne"

### AC-5 ↑↓ 行间移动与换选项 ← C-5
- 触发：在三行文字的输入栏里按 ↑↓
- Given：确认原型窗口，"通过并补充说明"输入栏有三行，光标在第二行
- When：按 ↑ 一次、再按 ↑ 一次；再按 ↓ 回到输入行；按 ↓ 三次
- Then：第一次 ↑ 光标到第一行；第二次 ↑ 光标到"通过"；↓ 回来后光标在离开时的位置（第一行）；之后 ↓ 两次到第三行，第三次 ↓ 光标到"其他"

### AC-6 提交与拒收 ← C-6
- 触发：回车
- Given：上限 4000 字的输入行
- When：分别输入空白回车；4001 字回车；"  第一行\n第二行  "回车
- Then：前两次窗口不关、不提交；第三次提交"第一行\n第二行"

### AC-7 字数与超出提示 ← C-7
- 触发：输入或粘贴
- Given：上限 4000 字
- When：粘贴 3990 字的单行文字，再输入 11 个字
- Then：输入栏显示"[paste #1 3990 chars]"和 11 个字；最后一行下面显示"超出 1 字，最多 4000 字"；回车不起作用

### AC-8 粘贴折叠 ← C-8
- 触发：粘贴
- Given：空输入栏
- When：先粘贴 3 行文字；再粘贴 42 行文字；再粘贴 1200 字的单行文字；回车
- Then：3 行原样显示；之后显示"[paste #1 +42 lines]"和"[paste #2 1200 chars]"；提交的文字是 3 行 + 42 行 + 1200 字的完整原文

### AC-9 底部提示 ← C-9
- 触发：光标移进、移出输入行
- Given：确认原型窗口；主代理提问窗口
- When：查看光标在输入行上和不在时的底部提示
- Then：确认原型窗口在输入行上时是"直接输入 · 回车确认 · Shift+Enter 换行 · ↑↓ 选择 · Esc 放弃这一版"；提问窗口在输入行上时是"直接输入 · 回车确认 · Shift+Enter 换行 · ↑↓ 选择 · Esc 暂不回答（问题保留，之后在对话里回答也行）"；不在输入行上时两者和现状一致

### AC-10 Esc 不变 ← C-10
- 触发：按 Esc
- Given：确认原型窗口和提问窗口的输入栏里都已有字
- When：按 Esc
- Then：确认原型窗口登记放弃；提问窗口按暂不回答处理

### AC-11 鼠标 ← C-11
- 触发：鼠标点击输入栏
- Given：全屏模式，"其他"输入栏有两行字，光标在"通过"；另一次是普通模式
- When：点击第一行第 5 个字；再点击第二行末尾后面的空白
- Then：全屏模式下第一次光标移到"其他"并停在第 5 个字前面，第二次停在第二行末尾；普通模式下窗口状态不变

## 验证路径
1. 80 列终端打开主代理提问窗口，在"其他"输入 100 个汉字 → 折成多行，pi 不退出。
2. Shift+Enter 换行，← 移到中间插字，Home、End、Backspace、Delete 各按一次 → 文字按预期变化。
3. 在第一行按 ↑ → 光标到上一个选项；再 ↓ 回来 → 回到原位置。
4. 粘贴 42 行 → 显示"[paste #1 +42 lines]"，回车后主代理收到完整原文。
5. 切换到 pi 全屏模式，点击输入栏的字 → 光标定位到点击处。
