# 验收窗口的其他

几个词先说清楚：
- 完成报告：PM 做完需求后提交的交付说明，状态面板上显示为"待验收"事项。
- 验收窗口：主代理请用户验收完成报告时弹出的提问窗口，固定选项是"验收通过""暂不验收"，另有一行可以自己输入。
- 登记：主代理把用户的原话交给程序，程序判断用户明确做了哪个决定后记下来；记下"返工"后完成报告作废，用户的话交回 PM 补做。

## 用户故事
### P0：作为用户，我想要对完成报告提问，而报告不被作废
**用例（主路径）**
- 场景：PM 交来"设置页改版"的完成报告，主代理弹出验收窗口。
- 操作：用户在"其他（自己输入）"写"深色模式下的对比度测过吗？"，回车。
- 预期：主代理回答这个问题；完成报告仍是待验收；主代理答完再弹一次验收窗口。

**用例（要修改）**
- 场景：同上。
- 操作：用户在"其他"写"开关放到标题右边"，回车。
- 预期：主代理按原话登记返工；完成报告作废；PM 收到"开关放到标题右边"并补做。

## 约束
- C-1：验收窗口的选项依次是"验收通过""暂不验收""其他（自己输入）"；窗口其他内容和按 Esc 的含义保持现状。
- C-2：主代理收到的验收事项说明里，关于这一行写："用户写在"其他（自己输入）"一行的话，是提问就先回答，完成报告仍待验收，答完用 one_company_user_interact purpose=panel-item 再请用户验收；明确要求修改时，按原话以 one_company_user_interact purpose=adjudicate 登记返工，报告作废，意见交回 PM。"
- C-3：主代理的规矩里，验收与关闭一条写明：用户在验收窗口"其他"一行写的是提问时先回答，不登记返工，完成报告仍待验收，答完再请用户验收；用户明确要求修改时，才按原话登记返工。
- C-4：用户写在"其他"一行的话被拿去登记时，只有这句话明确要求修改，程序才记下返工；只是提问时不记下任何决定，完成报告仍待验收。

## 验收
### AC-1 选项 ← C-1
- 触发：主代理请用户验收
- Given：一份待验收的完成报告
- When：查看验收窗口
- Then：选项依次是"验收通过""暂不验收""其他（自己输入）"；没有"返工（自己输入要改什么）"；底部提示的 Esc 那一段和现状一致

### AC-2 事项说明 ← C-2
- 触发：主代理读取待验收事项的说明
- Given：一份待验收的完成报告
- When：读取说明文字
- Then：含 C-2 的那段话；不含"返工（自己输入要改什么）"

### AC-3 主代理规矩 ← C-3
- 触发：主代理会话启动
- Given：任意
- When：读取主代理的规矩
- Then：验收与关闭一条含"提问时先回答，不登记返工"和"明确要求修改时，才按原话登记返工"

### AC-4 提问不作废报告 ← C-4
- 触发：主代理把"其他"一行的话拿去登记
- Given：一份待验收的完成报告
- When：一次用"深色模式下的对比度测过吗？"登记；一次用"开关放到标题右边"登记
- Then：第一次没有记下决定，报告仍待验收；第二次记下返工，报告作废，PM 收到这句原话

## 验证路径
1. PM 交来完成报告，主代理请用户验收 → 验收窗口第 3 项是"其他（自己输入）"。
2. 在"其他"写一个提问 → 主代理回答，状态面板上报告仍是待验收，主代理再弹验收窗口。
3. 在"其他"写一个修改要求 → 报告作废，PM 收到原话。
