# 程序窗口的输入栏能多行编辑；验收窗口的返工改为其他

## 背景与问题
- 程序窗口：程序弹出、请用户亲手选择的窗口，例如确认原型、主代理提问、面板事项提问（含验收）、项目规范更新。窗口里有一行可以自己输入文字，下面是输入栏，显示为"› <已输入的文字>"。
- 现在的输入栏只能在末尾加字和退格：不能移动光标改中间的字，不能换行分段。用户写较长的意见或说明时，打错一个字就要退格删到那里重写。
- 输入栏把所有文字拼成一行、不折行。80 列终端里输入约 36 个汉字，这一行就超出终端宽度，pi 的界面库遇到超宽的行会抛错，pi 直接退出，用户打的字全部丢失。
- 验收窗口：PM 交来完成报告后，主代理请用户验收时弹出的窗口，选项是"验收通过""暂不验收"和"返工（自己输入要改什么）"。用户写在返工一行的话有时只是一个提问（例如"深色模式下的对比度测过吗？"），叫"返工"会让人以为写了就要返工。

## 目标
- 所有程序窗口的输入栏都能：一行放不下时显示区跟着光标左右移动；行数多时跟着光标上下滚动并提示上下还有几行；没选中时收起成一行；Shift+Enter（或 Ctrl+J）换行；←→↑↓、Home、End 移动光标，在光标处插字、删字；大段粘贴折叠显示；pi 全屏模式下点击文字定位光标。
- 输入任意长度的文字时，窗口的每一行都不超过终端宽度，pi 照常运行。
- 验收窗口的"返工（自己输入要改什么）"改为"其他（自己输入）"：写的是提问时，主代理回答，完成报告仍待验收；明确要求修改时，才登记返工。

## 非目标
- pi 普通模式（非全屏）下用鼠标点击定位光标：普通模式下鼠标由终端负责选中复制和滚动，程序收不到点击。
- 用鼠标点击选项文字来选中选项。
- 在 pi 编辑器已有的功能之外另加编辑功能（例如选中一段文字整体删除）。
- 改变各窗口按 Esc 的含义。
- 验收窗口"验收通过""暂不验收"两个选项的行为。

## 整体验证路径
1. 主代理弹出确认原型窗口 → 光标移到"通过并补充说明"，输入 100 个汉字 → 这一行不折行，显示光标附近的一段、开头是"…"，pi 没有退出。
2. 按 Shift+Enter 再输入"第二段" → 输入栏多出一行；按 ← 移动光标到中间插入一个字 → 字插在光标处；在第一行按 ↑ → 光标移到上一个选项。
3. 粘贴一段 20 行的文字 → 输入栏里显示"[paste #1 +20 lines]"；回车 → 登记的补充说明是完整的 20 行原文。
4. PM 交来完成报告，主代理请用户验收 → 窗口第 3 项是"其他（自己输入）"；写"深色模式下的对比度测过吗？"回车 → 主代理回答，报告仍是待验收，主代理再问一次验收。
5. 在验收窗口的"其他"写"开关放到标题右边" → 主代理按原话登记返工，报告作废，PM 收到意见。

## 决策记录
- **质疑结论**：输入栏超宽会让 pi 直接退出、丢掉用户打的字，是必须修的鲁棒性问题（`/revise` 诊断，用户 2026-10-27 确认要修）；多行编辑和移动光标是用户 2026-10-27 追加的要求，长意见、长说明的场景真实存在。
- **输入栏直接换成 pi 自带的编辑器**（用户 2026-10-27 决定）：pi 主输入框用的编辑器本来就有折行、换行、移动光标、粘贴折叠和全屏鼠标定位，换上它顺带解决超宽退出。被否决的做法：先修折行、多行编辑另开分支做——同一处代码要写两遍，折行代码之后会被替换。
- **鼠标只在全屏模式下支持**（用户 2026-10-27 决定）：pi 普通模式下程序收不到鼠标事件；要接管鼠标就会让终端的选中复制和滚轮失效。被否决的做法：普通模式下也接管鼠标。
- **↑↓ 先在文字的行间移动，到第一行或最后一行再按才换选项**（用户 2026-10-27 决定）：和 pi 主输入框手感一致。被否决的做法：↑↓ 只换选项，文字里只能用 ←→ 移动。
- **大段粘贴折叠成"[paste #N +M lines]"**（用户 2026-10-27 决定）：和 pi 主输入框一致，窗口不会被一大段文字撑满；提交时交出完整原文。被否决的做法：全部展开显示。
- **验收窗口的"返工"改为"其他（自己输入）"**（用户 2026-10-27 决定）：用户的原话是"不一定是返工也可能是提问需要 Agent 去解答"，并要求确认原型窗口和验收窗口都统一成程序窗口默认的"其他（自己输入）"。被否决的做法：只改确认原型窗口；改名为"意见（自己输入：提问或要改的地方）"。
- **一行放不下时左右滚动、不自动折行**（用户 2026-10-27 决定）：用户要求"一行输入过长的话显示也需要跟着光标的位置走"；光标所在行跟着光标左右移动，其他行从开头显示，被挡住的一头用灰色"…"标出。被否决的做法：自动折成多行（pi 编辑器原本的显示）；所有行一起左右平移（短的行会整行看起来是空的）。
- **行数多时上下滚动并提示上下还有几行**（用户 2026-10-27 决定）：pi 编辑器自带的滚动提示在边框里，窗口去掉了边框，用户看不出有行被藏起来。用中文灰字"↑ 上面还有 N 行""↓ 下面还有 N 行"写在被藏起来的那一头。被否决的做法：保留 pi 的英文横线边框"─── ↑ 3 more ───"，和窗口其他文字风格不一致。
- **光标不在输入行上时输入栏收起成一行**（用户 2026-10-27 决定）：用户提出选到别的选项后只显示一共多少行；为了只写了一两行短字时也能认出写的是什么，收起成第一行开头加"…（共 N 行）"，只有一行时照原样显示。被否决的做法：只写"已输入 N 行"、不显示文字。
