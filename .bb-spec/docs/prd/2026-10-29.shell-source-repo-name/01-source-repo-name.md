# 「来源」行显示仓库名

Shell 任务详情页：在 `/one:ps` 打开的 Shell 任务页里选中一条按 Enter 看到的页面，逐行列出状态、来源、命令、目录、进程、耗时。「来源」行写开这个 Shell 的是谁，例如 `worker#a1b2c3` 表示 worker 子代理、运行编号前 6 位是 `a1b2c3`。子代理开的 Shell 来自某个仓库的守护进程（每个仓库一个、在后台跑子代理的进程）；主会话开的 Shell 来自本窗口。仓库名：仓库主目录的目录名，例如 `/Users/bb/Projects/企微BOT` 的仓库名是 `企微BOT`；仓库是另一个仓库的附加工作目录（git worktree）时，取它所属主仓库的目录名。

## 用户故事
### P0：作为在多仓库工作区里用 pi 的开发者，我想在 Shell 详情页看到子代理的 Shell 属于哪个仓库，以便判断要不要停掉它

**用例（主路径）**
- 场景：工作区里有 `企微BOT` 和 `admin-web` 两个仓库，`企微BOT` 里的 worker 正在跑 `pnpm test`。
- 操作：`/one:ps`，选中这条 Shell，按 Enter。
- 预期：「来源」行是 `worker#a1b2c3（仓库 企微BOT）`。

**用例（同名仓库）**
- 场景：工作区里有 `client/api` 和 `server/api` 两个仓库，目录名都是 `api`，两个仓库各有一条 worker 开的 Shell。
- 操作：分别打开两条的详情。
- 预期：「来源」行分别是 `worker#…（仓库 client/api）` 和 `worker#…（仓库 server/api）`。

**用例（上一层也同名）**
- 场景：工作区里有 `a/client/api` 和 `b/client/api` 两个仓库。
- 操作：分别打开两条子代理 Shell 的详情。
- 预期：「来源」行分别是 `（仓库 a/client/api）` 和 `（仓库 b/client/api）`。

**用例（本窗口的 Shell）**
- 场景：主会话自己执行了 `pnpm run dev`。
- 操作：打开它的详情。
- 预期：「来源」行是 `主 agent（本窗口）`，和现在一样。

## 约束
- C1：子代理开的 Shell，当前工作区里没有别的仓库和它的仓库同名时，「来源」行是 `<开它的代理>（仓库 <仓库名>）`，不出现仓库编号。
- C2：当前工作区里有几个仓库仓库名相同时，这几个仓库的「来源」括号里都写成 `仓库 <上层目录>/…/<仓库名>`：从仓库主目录往上逐层加目录名，用 `/` 隔开；这几个仓库加同样多层，加到它们互不相同为止。只和当前工作区找到的仓库比；名字不同的仓库不受影响，仍只写仓库名。
- C3：主会话开的 Shell，「来源」行是 `<开它的代理>（本窗口）`，不变。
- C4：「来源」行一行放不下时，和详情页其他行一样折到下一行，续行对齐到值那一列，文字不丢。
- C5：仓库名和加上的上层目录名里有控制字符（如换行、ESC）时，显示时去掉，「来源」行仍是一行文字（放不下时按 C4 折行），不会把终端排版打乱。

## 验收
- [ ] C1：工作区有 `企微BOT`、`admin-web` 两个仓库，`企微BOT` 的子代理 Shell 详情「来源」行等于 `worker#<6 位>（仓库 企微BOT）`，整页不出现该仓库编号的任何片段。
- [ ] C2：工作区有 `client/api`、`server/api`、`企微BOT` 三个仓库时，三者的「来源」括号分别是 `仓库 client/api`、`仓库 server/api`、`仓库 企微BOT`；工作区有 `a/client/api`、`b/client/api` 时分别是 `仓库 a/client/api`、`仓库 b/client/api`。
- [ ] C3：主会话 Shell 详情「来源」行等于 `主 agent（本窗口）`。
- [ ] C4：仓库名为 60 个字符的长名字、页面宽 80 列时，「来源」值折成两行，第二行从值那一列开始，两行拼起来是完整的 `<代理>（仓库 <长名字>）`。
- [ ] C5：仓库目录名或上层目录名含换行和 ESC 字符时，「来源」行的输出里没有这些控制字符。

## 验证路径
1. 在只有 `企微BOT` 仓库的工作区让 worker 跑后台命令，`/one:ps` → Enter → 「来源」行是 `worker#<6 位>（仓库 企微BOT）`。
2. 在含 `client/api`、`server/api` 的工作区重复 → 两条分别显示 `仓库 client/api`、`仓库 server/api`。
3. 选中主会话的 Shell → Enter → 「来源」行是 `主 agent（本窗口）`。
