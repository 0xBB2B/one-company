# 显示与填入

本文里的几个词：
- 主会话输入栏：pi 主会话窗口底部、用户打字发给主代理的那一栏。
- 一轮：用户发出一条消息，到主代理这次回复结束，算一轮。
- 输入建议：程序推测的、用户下一句最可能说的一句话，最多 60 个字。
- 灰色提示：输入建议在主会话输入栏里的样子，只是显示，不是输入栏里的真实文字。

## 用户故事
### P0：作为在 pi 主会话里和主代理对话的用户，我想要在空输入栏里看到灰色的建议，按一下右方向键就能用上，以便少打字又不被打扰

**用例（主路径）**
- 场景：主代理一轮刚结束，本轮的输入建议是"可以，按这个预览写 PRD"，主会话输入栏是空的。
- 操作：用户看到灰色提示后，按一次右方向键，再按 Enter。
- 预期：
  - 按右方向键前，输入栏里显示灰色的"可以，按这个预览写 PRD"，光标停在第一个字"可"上。
  - 按右方向键后，输入栏里是正常颜色的真实文字"可以，按这个预览写 PRD"，光标在末尾，消息没有发出。
  - 按 Enter 后，这句话作为用户消息发给主代理，新一轮开始，输入栏里没有提示。

**用例（边界 / 异常）**
- 场景：输入建议返回时，用户已经在输入栏里打了"等一下，我"。操作：用户把这几个字全删掉。预期：输入建议返回时输入栏里仍是"等一下，我"，没有提示；删空后灰色提示出现。
- 场景：灰色提示显示中。操作：用户打了一个字"不"。预期：提示消失，输入栏里只有"不"；再删掉"不"，灰色提示重新出现。
- 场景：输入建议比输入栏一行能放下的还长。操作：看输入栏，再按右方向键。预期：灰色提示截断显示，末尾是"…"；按右方向键后填进去的是完整的话。
- 场景：主代理刚结束一轮，输入建议还没返回。操作：看输入栏。预期：输入栏和平常一样是空的，没有"生成中"之类的字。
- 场景：这一轮没有输入建议（模型调用失败、推测不出、结果不合格）。操作：在空输入栏按右方向键。预期：输入栏还是空的，和 pi 原来的输入栏一样。

## 约束
- 显示条件：本轮有输入建议，而且主会话输入栏里没有任何字 → 显示灰色提示。光标停在第一个字上，这个字照光标的样子显示，后面的字是灰色。
- 等待期间：输入建议还没返回时，输入栏和平常一样，不显示任何提示文字。
- 有字时不显示：输入栏里有任何字 → 不显示灰色提示，也不改动输入栏里的字。这包括输入建议返回那一刻输入栏里已经有字的情况。
- 删空后重新出现：本轮的输入建议还没被清掉时，输入栏从有字变成没字 → 灰色提示重新出现。用右方向键填入过、又删空的也一样。
- 右方向键：
  - 输入栏为空且显示着灰色提示 → 输入栏的真实文字变成完整的输入建议，光标在末尾，不发送。
  - 输入栏为空且没有提示 → 和 pi 原来的输入栏一样。
  - 输入栏里有字 → 照常移动光标，和 pi 原来的输入栏一样。
- 太长时截断：输入建议在输入栏一行里放不下 → 显示时截断，末尾加"…"。按右方向键填进去的仍是完整的话。
- 清掉：用户发出一条消息，或者主代理开始新一轮 → 本轮的输入建议清掉，输入栏里的灰色提示随即消失。下一次正常结束的一轮生成新的输入建议后才再显示。
- 其他按键不变：除了输入栏为空且显示着提示时的右方向键，其他按键的行为都和 pi 原来的主会话输入栏一样。状态面板（主会话输入栏下方显示需求运行情况的区域）用的上、下、回车、p 键也不受影响。
- 只在交互模式下显示：pi 以打印模式或 RPC 模式运行时不替换输入栏。

## 验收
- [ ] 有输入建议、输入栏为空 → 显示灰色提示，第一个字照光标样子显示，其余是灰色。
- [ ] 输入建议还没返回时，输入栏里没有任何提示文字。
- [ ] 输入建议返回时输入栏里已有字 → 输入栏里的字不变，不显示提示。
- [ ] 显示提示时打一个字 → 提示消失，输入栏只有这个字；删空后提示重新出现。
- [ ] 用右方向键填入后再删空 → 提示重新出现。
- [ ] 输入栏为空、显示着提示时按右方向键 → 输入栏文字等于完整的输入建议，光标在末尾，没有发送消息。
- [ ] 输入栏为空、没有提示时按右方向键 → 输入栏还是空的。
- [ ] 输入栏有字、光标不在末尾时按右方向键 → 光标右移一格，文字不变。
- [ ] 输入建议宽度超出输入栏一行 → 显示的内容以"…"结尾、没有超出一行；按右方向键后输入栏文字等于完整的输入建议。
- [ ] 用户发出消息后，输入栏不显示旧提示；主代理开始新一轮后，输入栏不显示旧提示。
- [ ] 显示提示时，Enter、Esc、上下方向键等其他按键的行为和 pi 原来的主会话输入栏一样；状态面板的上、下、回车、p 键照常可用。
- [ ] 打印模式、RPC 模式下不替换主会话输入栏。

## 验证路径
1. 让一轮正常结束、输入建议返回，输入栏为空 → 输入栏显示灰色提示，光标在第一个字上。
2. 打一个字 → 提示消失；删掉 → 提示重新出现。
3. 按右方向键 → 提示变成真实文字，光标在末尾，没有发送。
4. 删空输入栏 → 提示重新出现；再按右方向键、按 Enter → 消息发出，新一轮开始，输入栏里没有旧提示。
5. 下一轮结束前先在输入栏打字，等输入建议返回 → 输入栏里的字不变，没有提示；删空 → 提示出现。
6. 让输入建议是 60 个汉字，把终端窗口调窄到放不下一行 → 提示截断，末尾是"…"；按右方向键 → 填进去的是完整的 60 个字。
