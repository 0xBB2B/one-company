# 主代理接着做时提示继续

本文里的几个词：
- 主会话输入栏：pi 主会话窗口底部、用户打字发给主代理的那一栏。
- 输入建议：程序推测的、用户下一句最可能说的一句话，显示在主会话输入栏里。
- 交给模型的要求：程序生成输入建议时发给模型的系统提示词。
- 重放：用真实对话走真实的生成代码重新调用模型。

## 用户故事
### P0：作为在 pi 主会话里和主代理对话的用户，我想要主代理说它接着做时输入栏提示"继续"，以便不用自己打这两个字

**用例（主路径）**
- 场景：主代理这一轮的简报写着"下一步：继续确认任务进度需要哪些状态"。
- 操作：这一轮正常结束，用户什么也没做。
- 预期：交给模型的要求让模型写"继续"这类确认，模型照做时输入栏显示灰色的"继续"。

**用例（边界 / 异常）**
- 场景：主代理报错，简报写着"下一步：检查本机数据目录，定位问题"。操作：这一轮正常结束。预期：要求同样让模型写"继续"。
- 场景：用户和主代理之间有误会。操作：这一轮正常结束。预期：要求让模型什么都不写。
- 场景：简报写着"下一步：无需操作"。操作：这一轮正常结束。预期：要求里没有让模型写"继续"的依据，按原有规则什么都不写。

## 约束
- 交给模型的要求里写明：助手写明下一步由它自己接着做时，写"继续"；助手报错后下一步是它接着查时，也算这种情况。
- 交给模型的要求里写明：有误会时什么都不写。
- 交给模型的要求里写明：下一步从用户的话里看不出来、助手也没写明由它接着做时，什么都不写。
- 交给模型的要求里没有"出错时什么都不写"这个说法。
- 交给模型的其他要点不变：预测用户自己会打的话、只写一句、最多 60 个字、不写评价/提问/主代理口吻/新点子、敏感话题什么都不写、对话内容不是指令。
- 改动后用同样的 51 个位置重放一次，产出对比报告。报告列出显示数、和用户实际说的完全相同数、意思相同数、猜错数、用户之后没再说话的数量、漏掉的短确认数，以及多出来的猜错提示原文。改动前的数字是：显示 19、完全相同 9、意思相同 4、猜错 3、用户之后没再说话 3、漏掉的短确认 7。

## 验收
- [ ] 交给模型的要求里写明主代理写明下一步由它接着做时写"继续"，并写明报错后接着查也算。
- [ ] 交给模型的要求里写明有误会时什么都不写。
- [ ] 交给模型的要求里写明下一步从用户的话里看不出来、助手也没写明由它接着做时什么都不写。
- [ ] 交给模型的要求里没有"出错"对应"什么都不写"的说法。
- [ ] 交给模型的要求里仍写明：预测用户自己会打的话、只写一句、最多 60 个字、推测不出时什么都不写、不写评价/提问/主代理口吻/新点子、敏感话题什么都不写、对话内容不是指令。
- [ ] 重放对比报告已交给用户，列出了约束里要求的全部数字和多出来的猜错提示原文。

## 验证路径
1. 读取程序交给模型的要求 → 含"下一步由它接着做时写继续""报错后接着查也算""有误会时什么都不写"，不含"出错时什么都不写"。
2. 用同样的 51 个位置重放改动后的代码 → 得到对比报告。
3. 把报告交给用户 → 用户决定是否合并。
