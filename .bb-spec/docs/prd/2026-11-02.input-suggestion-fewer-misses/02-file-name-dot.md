# 文件名里的点不算句号

本文里的几个词：
- 输入建议：程序推测的、用户下一句最可能说的一句话，显示在主会话输入栏里。
- 多句话规则：模型返回的文字里，句号、问号、感叹号后面还有文字时，这次结果不算数，没有输入建议。

## 用户故事
### P0：作为在 pi 主会话里和主代理对话的用户，我想要含文件名的建议也能显示，以便不用自己打文件名

**用例（主路径）**
- 场景：模型返回"读取 README.md"。
- 操作：等返回。
- 预期：输入建议是"读取 README.md"。

**用例（边界 / 异常）**
- 场景：模型返回"读取《企微BOT-需求整理提示词.md》，按其中要求重新整理需求"。操作：等返回。预期：这句话原样成为输入建议。
- 场景：模型返回"改 vite.config.ts 再跑测试"。操作：等返回。预期：这句话原样成为输入建议。
- 场景：模型返回"Run tests.Then commit"。操作：等返回。预期：没有输入建议。
- 场景：模型返回"读取 README.md。然后提交"。操作：等返回。预期：没有输入建议。

## 约束
- 英文句点后面紧跟小写英文字母（a 到 z，中间没有空白）→ 这个点不算句号。
- 其他情况的多句话规则不变：
  - 英文句点后面有空白再跟文字 → 算句号。
  - 英文句点后面紧跟大写英文字母或汉字 → 算句号。
  - 两边都是数字的点是小数点，不算句号，例如"v1.2"。
  - 中文句号、问号、感叹号（中文或英文）后面还有文字 → 算句号。
- 文字末尾的句号、问号、感叹号后面没有文字 → 不算多句话，例如"跑一下测试。"。

1. 让模型返回"读取 README.md" → 这句话成为输入建议。
2. 让模型返回"Run tests.Then commit" → 没有输入建议，也没有弹错误。
3. 让模型返回"读取 README.md。然后提交" → 没有输入建议。
