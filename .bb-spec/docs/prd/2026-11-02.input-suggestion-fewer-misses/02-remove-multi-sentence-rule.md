# 删掉多句话规则

本文里的几个词：
- 输入建议：程序推测的、用户下一句最可能说的一句话，显示在主会话输入栏里。
- 结果判定：模型返回文字后，程序按一组规则检查，命中任何一条就没有输入建议。
- 交给模型的要求：程序生成输入建议时发给模型的系统提示词。

## 用户故事
### P0：作为在 pi 主会话里和主代理对话的用户，我想要含文件名的建议也能显示，以便不用自己打文件名

**用例（主路径）**
- 场景：模型返回"读取 README.md"。
- 操作：等返回。
- 预期：输入建议是"读取 README.md"。

**用例（边界 / 异常）**
- 场景：模型返回"读取《企微BOT-需求整理提示词.md》，按其中要求重新整理需求"。操作：等返回。预期：这句话原样成为输入建议。
- 场景：模型返回"跑测试。然后提交"。操作：等返回。预期：这段话原样成为输入建议。
- 场景：模型返回两句话，总长 61 个字。操作：等返回。预期：超过 60 个字，没有输入建议。
- 场景：模型返回"我来跑测试。然后提交"。操作：等返回。预期：以主代理口吻开头，没有输入建议。

## 约束
- 结果判定的规则是这几条：是空的、超过 60 个字、含换行或控制字符、含 `*`、整句是"无建议"这类自述、整句被括号包住、含评价语、以主代理口吻开头。句号、问号、感叹号后面还有文字这件事本身不让结果作废。
- 模型返回两句话时，只要没有命中上面的规则 → 原样成为输入建议。
- 模型返回的话命中上面的规则时，有几句话都没有输入建议。
- 交给模型的要求里仍写明"只写一句"和"不写多句话"。

## 验收
- [ ] 模型返回"读取 README.md""读取《企微BOT-需求整理提示词.md》，按其中要求重新整理需求""改 vite.config.ts 再跑测试""升级到 v1.2 再跑测试" → 各自原样成为输入建议。
- [ ] 模型返回"跑测试。然后提交""跑测试！再提交""要跑吗？跑吧""Run tests. Then commit""Run tests! Then commit""跑测试!然后提交""Run tests.Then commit" → 各自原样成为输入建议。
- [ ] 模型返回 61 个字的两句话 → 没有输入建议。
- [ ] 模型返回"我来跑测试。然后提交""谢谢。然后提交""跑测试。\n然后提交" → 没有输入建议。
- [ ] 交给模型的要求里写明只写一句、不写多句话。

## 验证路径
1. 让模型返回"读取 README.md" → 这句话成为输入建议。
2. 让模型返回"跑测试。然后提交" → 这段话成为输入建议。
3. 让模型返回"我来跑测试。然后提交" → 没有输入建议，也没有弹错误。
