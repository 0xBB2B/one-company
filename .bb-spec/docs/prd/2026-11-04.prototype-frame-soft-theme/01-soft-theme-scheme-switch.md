# 柔和明暗配色和右上角方案切换

几个词先说清楚：
- 原型外框：程序给每份原型生成的固定外框，由切换栏、框上方一行、隔离框、说明区组成。
- 切换栏：外框左边的栏，放原型名称和切换按钮，上线后不存在。
- 框上方一行：隔离框正上方的一行，左边写固定提示和当前看的页面、画面，右边放按钮。
- 隔离框：显示设计师交的页面的独立区域（iframe），里面的样式和外框分开。
- 说明区：隔离框下方放这次设计说明的区域，上线后不存在。
- 画面：一个页面的一种可切换显示，图形界面是一种状态，终端界面是一步。
- 方案清单：设计师交稿时附上的一组方案名称，程序按顺序编字母 A 到 F。
- 明暗按钮：框上方一行最右端的「☀ 明亮」「☾ 暗黑」两个按钮，只切换外框的配色。

## 用户故事
### P0：作为看原型的用户，我想外框不刺眼，深色系统下也是深色
**用例（主路径）**
- 场景：系统是浅色外观，设计师交了"订单导出"第 2 版，含订单列表（正常、空数据、加载中、出错）和订单详情两个页面。
- 操作：浏览器自动打开这份原型。
- 预期：外框是雾灰蓝底（`#d5dae1`）带浅网格，线条、标签和虚线是灰蓝色（`#47607f`）；切换栏里选中的"订单列表""正常"是细灰蓝线框加浅色填充；隔离框里的页面是白底，和改之前一样；「☀ 明亮」显示为选中。

**用例（深色系统）**
- 场景：同上，系统是深色外观。
- 操作：打开原型。
- 预期：外框是石墨深灰底（`#26282c`），线条是浅灰色（`#8e9aa8`）；「☾ 暗黑」显示为选中；隔离框里的页面和浅色系统下完全一样。

**用例（手动切换）**
- 场景：系统是浅色外观，原型已打开。
- 操作：点「☾ 暗黑」；再把系统外观换成深色，又换回浅色；最后关掉网页重新打开。
- 预期：点完外框变成暗黑；系统外观来回换时外框一直是暗黑；重新打开后外框又是明亮，跟系统一致。

### P0：作为对比方案的用户，我想一眼分清哪组按钮切方案
**用例（主路径）**
- 场景：设计师交了 4 个方案："表格""卡片""紧凑表格""大字卡片"。
- 操作：打开原型，先点切换栏的"空数据"，再点右上角「方案 C：紧凑表格」。
- 预期：框上方右侧依次是"方案"、4 个方案按钮、明暗按钮；切换栏顶部写"当前：方案 A：表格"，下面一行写"最后选哪个，在“确认原型”窗口里定"，再往下只有"页面""状态"两组按钮。点完"空数据"后框上方左边写"订单列表 · 空数据"；点完方案 C 后隔离框重新载入方案 C 的空数据画面，「方案 C：紧凑表格」显示为选中，切换栏顶部变成"当前：方案 C：紧凑表格"，"空数据"仍是选中。

**用例（只有 1 个方案）**
- 场景：设计师没附方案清单。
- 操作：打开原型。
- 预期：框上方右侧只有明暗按钮；切换栏顶部没有"当前："和"最后选哪个"两行。

**用例（方案多、名字长）**
- 场景：设计师附了 6 个方案，每个名字写满 20 字，窗口宽 1440 像素。
- 操作：打开原型。
- 预期：方案按钮一行放不下时换到下一行，靠右排；明暗按钮排在最后；页面不出现横向滚动条。

## 约束
- C-1：明亮主题下，切换栏、框上方一行和说明区用同一种底色 `#d5dae1`，铺 20 像素一格的网格线 `rgba(71, 96, 127, .06)`；正文文字 `#1d2633`，次要文字 `#4f5b6b`；标签边框和文字、切换栏右边缘的虚线、隔离框外圈的虚线、说明区顶边的虚线都是 `#47607f`；普通按钮边框和分隔线是 `#b7bfca`。
- C-2：暗黑主题下，底色 `#26282c`，网格线 `rgba(255, 255, 255, .03)`；正文文字 `#d4d4d4`，次要文字 `#8f949b`；标签、虚线 `#8e9aa8`；普通按钮边框和分隔线 `#3a3d43`。
- C-3：选中的按钮（切换栏的页面、画面按钮，右上角的方案按钮和明暗按钮）显示为 1 像素实线边框加浅填充、文字加粗：明亮主题边框 `#47607f`、填充 `#c2cad5`、文字 `#1d2633`；暗黑主题边框 `#8e9aa8`、填充 `#33363c`、文字 `#e6e6e6`。鼠标移到没选中的按钮上时，边框变成 C-1、C-2 的虚线颜色。
- C-4：两种主题下，隔离框背景都是白色，设计师交的页面显示得完全一样；切换主题时隔离框不重新载入，页面里输入的内容还在。
- C-5：框上方一行最右端是「☀ 明亮」「☾ 暗黑」两个按钮，当前主题的按钮显示为选中。打开原型时按系统外观选主题；用户没点过明暗按钮时，系统外观变化，主题跟着变；点过之后以点的为准，系统外观再变也不跟。选择不存进浏览器，重新打开原型时又按系统外观选。浏览器不支持监听系统外观变化时，只按打开时的系统外观选，原型照常显示和切换。
- C-6：有方案清单时，框上方一行右侧从左到右依次是文字"方案"、每个方案一个按钮（写"方案 <字母>：<名称>"）、明暗按钮；当前方案的按钮显示为选中。没有方案清单时，"方案"和方案按钮都不显示。
- C-7：切换栏从上到下依次是：标签"设计说明 · 不属于页面"、原型名称、"第 N 版 · 这一栏上线后不存在"；有方案清单时接着是"当前：方案 <字母>：<名称>"和"最后选哪个，在“确认原型”窗口里定"两行；最后是"切换要看的内容"（页面组、当前页面的切换组）。切换栏里没有方案按钮，也没有"这份原型有 N 个方案，点这里切换对比"提示框。
- C-8：框上方一行左侧是"▼ 被设计的页面：只有这个框里的内容要实现"，后面是当前的页面名称和画面名称，用" · "隔开，只有一项可选的组不写；这里不显示方案名。
- C-9：点右上角的方案按钮，隔离框重新载入这个方案的当前画面，页面和画面的选中项不变，切换栏顶部的"当前："跟着变。点方案按钮不登记任何决定，用户的决定只认"确认原型"窗口。
- C-10：框上方一行放不下时折行：右侧按钮整组换到下一行靠右，明暗按钮始终排在最后。6 个方案名各写满 20 字时，窗口宽 390、761、1440 像素下都没有横向滚动条。
- C-11：窗口宽度不超过 760 像素时，从上到下依次是切换栏、框上方一行、隔离框、说明区；切换栏的右边缘虚线换成底边虚线。

## 验收
- [ ] C-1：明亮主题下切换栏、框上方一行、说明区的底色都是 `#d5dae1`，网格、文字、虚线、普通按钮边框的颜色和约束一致。
- [ ] C-2：暗黑主题下各处颜色和约束一致。
- [ ] C-3：两种主题下，选中按钮的边框、填充、文字颜色和加粗与约束一致；没选中的按钮鼠标移上去时边框变色。
- [ ] C-4：切换主题前后，隔离框的白底和页面内容不变，隔离框没有重新载入，之前在页面里输入的内容还在。
- [ ] C-5：浅色系统打开选中明亮、深色系统打开选中暗黑；没点过明暗按钮时系统外观变化主题跟着变；点过之后不跟；重新打开又按系统外观；浏览器不支持监听系统外观变化时，原型照常显示和切换。
- [ ] C-6：有 4 个方案时，框上方右侧依次是"方案"、4 个方案按钮、明暗按钮，方案 A 选中；没有方案清单时只有明暗按钮。
- [ ] C-7：有方案清单时，切换栏的顺序和固定文字与约束一致；没有方案清单时没有"当前："和"最后选哪个"两行；两种情况下切换栏里都没有方案按钮和方案提示框。
- [ ] C-8：框上方左侧的固定文字和"页面 · 画面"正确，切换后跟着变，任何时候都不显示方案名。
- [ ] C-9：选中"空数据"后点方案 C，隔离框载入方案 C 的空数据画面，"空数据"仍选中，切换栏顶部变成"当前：方案 C：<名称>"；点完后原型仍在等确认，看板记录没有变化。
- [ ] C-10：6 个方案名各写满 20 字时，窗口宽 390、761、1440 像素下都没有横向滚动条，明暗按钮排在最后。
- [ ] C-11：窗口宽 390 像素时，从上到下是切换栏、框上方一行、隔离框、说明区，切换栏底边是虚线。

## 验证路径
1. 用一份带 2 个页面、4 种状态、4 个方案的交稿拼出原型，在浅色系统下用浏览器打开 → 外框是雾灰蓝，右上角依次是"方案"、4 个方案按钮、明暗按钮，切换栏顶部写"当前：方案 A：<名称>"。
2. 点"空数据"，再点「方案 C」→ 隔离框显示方案 C 的空数据画面，切换栏顶部和选中项跟着变。
3. 点「☾ 暗黑」→ 外框变成石墨深灰，隔离框里的内容不变；切换系统外观 → 外框不跟。
4. 重新打开 → 外框跟系统外观一致。
5. 换一份没有方案清单的交稿 → 右上角只有明暗按钮，切换栏顶部没有"当前："。
6. 换一份 6 个长名字方案的交稿，窗口拉到 390、761、1440 像素宽 → 都没有横向滚动条，390 像素宽时从上到下是切换栏、框上方一行、隔离框、说明区。
