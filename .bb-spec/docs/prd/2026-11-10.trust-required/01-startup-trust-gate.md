# 启动时授信与停用

授信记录：pi 在 `~/.pi/agent/trust.json` 里给每个目录记的信任决定，有信任、不信任、空、读不了四种情况（读不了指文件写坏、值不合法或所在目录只读）。项目：主仓库根目录，不在 Git 仓库里时是 pi 启动的目录；授信记录从项目目录往上找最近的一条。启用：本次会话里 OneCompany 连接守护进程、显示状态面板、向主代理注入规则、OneCompany 的工具对模型可用、`/one:` 命令正常打开页面。停用：以上都不做，`/one:` 命令只回一行说明，pi 自己的功能照常。`<文件>`：授信记录文件路径，家目录写成 `~`。`<原因>`：错误信息的第一行。

## 用户故事
### P0：作为在新项目里打开 pi 的用户，我想要启动时就被问要不要在这里用 OneCompany，以便受信任的项目里 OneCompany 和项目层一起生效

**用例（主路径：信任）**
- 场景：项目 `~/Projects/Codex5x`，`trust.json` 里没有它。
- 操作：在这个项目里启动 pi，在弹窗里直接回车（默认"信任"）。
- 预期：弹窗出来前没有状态面板；选完后 `trust.json` 里 `~/Projects/Codex5x` 为 true，主窗口绿字"✓ 已把本项目设为受信任，OneCompany 已启用"，状态面板出现，OneCompany 的工具对模型可用；退出再启动不再弹窗、直接启用。

**用例（主路径：不信任）**
- 场景：同上。
- 操作：启动 pi，选"不信任"。
- 预期：`trust.json` 里这一项为 false；灰字"OneCompany 在这个项目停用：已记为不信任。要用时在 pi 里输入 /trust 选 Trust，再重开 pi"；没有状态面板；再启动不弹窗，灰字"OneCompany 在这个项目停用：你选过不信任这个项目。要用时在 pi 里输入 /trust 选 Trust，再重开 pi"。

**用例（主路径：这次不用）**
- 场景：同上。
- 操作：启动 pi，按 Esc；然后输入 `/one:setting`。
- 预期：`trust.json` 不变；灰字"OneCompany 这次没有启用，下次启动 pi 时再问"；`/one:setting` 不打开页面，回一行灰字"OneCompany 在这个项目停用：项目还没授信。重开 pi 时在弹窗里选信任即可启用"；再启动又弹窗。

**用例（异常：授信记录读不了）**
- 场景：`trust.json` 内容是 `{"a": true,}`。
- 操作：启动 pi。
- 预期：不弹窗，停用，红字"✗ OneCompany 在这个项目停用：读不了授信记录 ~/.pi/agent/trust.json：Failed to read trust store …；改好这个文件后重开 pi"。

**用例（异常：写授信记录失败）**
- 场景：`trust.json` 所在目录可写，`trust.json` 是只读的 `{}`。
- 操作：启动 pi，选"信任"。
- 预期：`trust.json` 仍是 `{}`；停用；红字"✗ 没有记下你的选择：<原因>；OneCompany 这次没有启用"。

## 约束
- C-1：每次会话开始（pi 启动、`/new`、`/resume`、`/fork`、`/reload`）按项目的授信记录决定本次会话启用还是停用：记录为信任 → 启用；空、不信任、读不了 → 停用。会话开始之后授信记录变了，本次会话的启用 / 停用不变。
- C-2：停用时：不连接也不拉起守护进程，不显示状态面板，不向主代理注入 OneCompany 的规则，OneCompany 的工具对模型不可用；pi 自带的工具和命令照常。启用时以上行为和现在一样。
- C-3：只在 pi 刚启动、有界面、记录为空时弹窗。没有界面（print、JSON、RPC 模式）时不弹窗、不提示；`/new`、`/resume`、`/fork`、`/reload` 时不弹窗。弹窗出来之前按停用处理。
- C-4：弹窗样式和设置页"复制到哪一层"的窗口一样（程序窗口、警告色）。内容依次：标题"要在这个项目里使用 OneCompany 吗？"；"项目：<项目路径，家目录写 ~>"；"OneCompany 只在受信任的项目里运行。信任后，项目里的 .pi 设置、角色定义和 skill 也会一起生效。"；灰字"你的选择会记进 pi 的授信记录，和在 pi 里输入 /trust 一样。"；选项"信任"（说明"启用 OneCompany，以后不再问"）、"不信任"（"这个项目不用 OneCompany，以后不再问；要改时输入 /trust"）、"这次不用"（"这次不启用，下次启动 pi 时再问"），都不标推荐，光标默认在"信任"；提示行"↑↓ 选择 · 回车确认 · Esc 这次不用"。
- C-5：选"信任" → 项目记为 true，启用，主窗口绿字"✓ 已把本项目设为受信任，OneCompany 已启用"。
- C-6：选"不信任" → 项目记为 false，停用，灰字"OneCompany 在这个项目停用：已记为不信任。要用时在 pi 里输入 /trust 选 Trust，再重开 pi"。
- C-7：选"这次不用"或按 Esc → 不写授信记录，停用，灰字"OneCompany 这次没有启用，下次启动 pi 时再问"。
- C-8：选"信任"或"不信任"后写授信记录失败 → 记录不变，停用，红字"✗ 没有记下你的选择：<原因>；OneCompany 这次没有启用"。
- C-9：有界面、会话开始时记录为不信任 → 不弹窗，停用，灰字"OneCompany 在这个项目停用：你选过不信任这个项目。要用时在 pi 里输入 /trust 选 Trust，再重开 pi"。
- C-10：有界面、会话开始时记录读不了 → 不弹窗，停用，红字"✗ OneCompany 在这个项目停用：读不了授信记录 <文件>：<原因>；改好这个文件后重开 pi"。
- C-11：有界面、`/new`、`/resume`、`/fork`、`/reload` 时记录为空 → 停用，灰字"OneCompany 这次没有启用，下次启动 pi 时再问"。
- C-12：停用时输入任何 `/one:` 命令 → 不打开页面、不做任何改动，主窗口一行说明：记录为空时灰字"OneCompany 在这个项目停用：项目还没授信。重开 pi 时在弹窗里选信任即可启用"；不信任时灰字"OneCompany 在这个项目停用：你选过不信任这个项目。要用时在 pi 里输入 /trust 选 Trust，再重开 pi"；读不了时红字"✗ OneCompany 在这个项目停用：读不了授信记录 <文件>：<原因>；改好这个文件后重开 pi"。原因按会话开始时的记录写。
- C-13：以上所有提示都不加 pi 的"Error: "前缀；终端宽 36 到 80 列时，弹窗和提示每一行都不超过终端宽度，放不下折行。

## 验收
- [ ] AC-1 ← C-1：记录为信任时启动、`/new`、`/resume`、`/fork`、`/reload` 都启用；为空、不信任、读不了时都停用；会话开始后把记录从信任改成不信任，本次会话仍启用。
- [ ] AC-2 ← C-2：停用时状态面板不出现、守护进程没有被连接或拉起、OneCompany 的工具不在模型可用的工具里、主代理没有收到 OneCompany 的规则；启用时这些都和现在一样。
- [ ] AC-3 ← C-3：刚启动 + 有界面 + 记录为空才弹窗；没有界面、`/new` 等情况不弹窗。
- [ ] AC-4 ← C-4：弹窗标题、各行文字、三个选项及说明、默认光标、提示行符合约束，没有"推荐"。
- [ ] AC-5 ← C-5：选信任后 `trust.json` 里项目为 true，启用，绿字符合约束。
- [ ] AC-6 ← C-6：选不信任后项目为 false，停用，灰字符合约束。
- [ ] AC-7 ← C-7：选这次不用、按 Esc，`trust.json` 不变，停用，灰字符合约束；再启动又弹窗。
- [ ] AC-8 ← C-8：`trust.json` 只读时选信任，内容不变，停用，红字符合约束。
- [ ] AC-9 ← C-9：记录为 false 时启动不弹窗，停用，灰字符合约束。
- [ ] AC-10 ← C-10：`trust.json` 写坏、所在目录只读时启动不弹窗，停用，红字符合约束。
- [ ] AC-11 ← C-11：记录为空时 `/reload`，不弹窗，停用，灰字符合约束。

## 验证路径
1. 新建临时 Git 项目，`trust.json` 里没有它 → 启动 pi，看弹窗和"弹窗前没有状态面板"（AC-3、AC-4、AC-2）。
2. 按 Esc → 看灰字；输入 `/one:setting` → 看说明，没打开页面（AC-7、AC-12）。
3. 重开选信任 → 看绿字、状态面板、`trust.json`（AC-5）；`/reload` → 仍启用（AC-1）。
4. 改成 false 重开 → 看灰字（AC-9）；`/one:examples` → 看说明（AC-12）。
5. 写坏 `trust.json` 重开 → 看红字（AC-10）。
6. 把 `trust.json` 设成只读的 `{}`，删掉这一项后重开选信任 → 看红字（AC-8）。
7. 用 `pi -p` 在记录为空的项目里跑一句话 → 不弹窗、OneCompany 工具不可用（AC-3、AC-2）。
8. 把终端拉到 36、44、60 列重复第 1、5 步 → 每行不超宽（AC-13）。
