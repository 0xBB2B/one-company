# 删掉半信任分支

启用：本次 pi 会话里 OneCompany 在运行，这只在会话开始时项目的授信记录为"信任"时发生。项目层：项目 `.pi/` 下的角色定义、设定和 skill。设置页：输入 `/one:setting` 打开的页面。存到哪一层：设置页里修改模型设定、Git 交付、合并方式时最后一步选存到项目层还是用户层的选择框。

## 用户故事
### P0：作为在受信任项目里用 OneCompany 的用户，我想要设置页和样例复制里没有授信相关的提示和限制，以便直接使用项目层

**用例（主路径）**
- 场景：项目 `~/Projects/Codex5x` 已受信任，OneCompany 已启用，`.pi/agents/` 下有 5 份定义。
- 操作：输入 `/one:setting`，看页面；进「模型」把 PM 存到项目层；按 C 把 worker 复制到项目层；输入 `/one:examples` 复制一套样例到项目层。
- 预期：页面顶部没有授信相关的黄字，「问题」里没有授信那一条，5 份项目层定义在各自分区里；"存到哪一层"里项目层写".pi/settings.json · 只对这个项目生效"，下面没有授信说明；保存、复制的成功提示里没有"已把本项目设为受信任"；`trust.json` 全程不被改写。

## 约束
- C-1：设置页任何状态下都没有授信相关的文字：顶部没有"项目还没设为受信任 / 项目未受信任 / 读不了授信记录"黄字，「问题」里没有授信那一条，项目层的角色定义和设定都加载。
- C-2：模型设定、Git 交付、合并方式三处的"存到哪一层"里，项目层总是可选，说明".pi/settings.json · 只对这个项目生效"，选择框下面没有授信说明；保存到项目层不读、不写授信记录，成功和失败提示里都没有"已把本项目设为受信任"。
- C-3：设置页按 C 复制定义的选层窗口里，项目层的说明是目标文件路径，只在目标位置已有同名文件时变暗；复制到项目层不读、不写授信记录，提示里没有"已把本项目设为受信任"。
- C-4：`/one:examples` 第一个窗口里每套样例的"项目层：<状态>"写项目层实际的复制状态；选层窗口里项目层说明"<项目路径>/ · 只对这个项目生效"，只在已全部复制时变暗；复制到项目层不读、不写授信记录，提示里没有"已把本项目设为受信任"。
- C-5：会话开始之后授信记录变了（比如变成不信任或读不了），设置页和 `/one:examples` 的行为仍按 C-1 到 C-4，不出现授信相关的文字。
- C-6：终端宽 36 到 80 列时，本子需求改动的每一行都不超过终端宽度。

## 验收
- [ ] AC-1 ← C-1：启用的会话里打开设置页，没有授信相关黄字和「问题」条目，项目层定义出现在列表里。
- [ ] AC-2 ← C-2：三处"存到哪一层"项目层可选、说明符合约束、没有授信说明；存到项目层后 `trust.json` 内容不变，提示里没有那句话。
- [ ] AC-3 ← C-3：按 C 复制到项目层，`trust.json` 不变，提示里没有那句话；目标已有同名文件时项目层变暗。
- [ ] AC-4 ← C-4：`/one:examples` 窗口一写实际复制状态，选层窗口说明符合约束，复制后 `trust.json` 不变，提示里没有那句话。
- [ ] AC-5 ← C-5：启用后把 `trust.json` 改成 false 或写坏，再打开设置页和 `/one:examples`，行为同 AC-1 到 AC-4。
- [ ] AC-6 ← C-6：36、44、60、80 列下改动的行不超宽。

## 验证路径
1. 在已受信任的项目里启动 pi，打开 `/one:setting` → 没有授信相关内容（AC-1）。
2. 把 PM 存到项目层、按 C 复制到项目层 → 看提示和 `trust.json`（AC-2、AC-3）。
3. `/one:examples` 复制一套到项目层 → 看窗口和提示（AC-4）。
4. 把 `trust.json` 写坏，在同一会话里重复 1～3 → 行为不变（AC-5）。
5. 把终端拉到 36、44 列重复第 1 步（AC-6）。
