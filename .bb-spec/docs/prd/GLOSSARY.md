# 术语表

> 全项目术语唯一权威源，仅 /prd 维护。跨语言 / 跨文档以英文锚点对齐；别名只登记实际用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| role-definition | 一份描述可派工子代理的文件：写明名称、描述、职责、模型、思考等级、skills、mcp 和正文；分内置、用户、项目三层，同名时上层覆盖下层 | 简体「角色定义」 |
| role-rules | 程序按职责（pm、worker、reviewer、qa、explore）固定加进提示词的流程规矩，放在定义正文之后，优先于正文，用户改不到 | 简体「职责规矩」 |
| definition-body | 角色定义文件里头部设置下面的那段文字，用户在这里写专长和偏好；可以为空 | 简体「定义正文」「正文」 |
| internal-agent | 程序内部的单次模型调用，不能派工：解释器（把用户原话解读成结构化决定）和草稿核验器（核对需求草稿是不是用户原话要求的） | 简体「内部代理」 |
| settings-tab | /one:agents 分类栏最右边的一栏，修改 PM 和两个内部代理的模型与思考等级 | 简体「设定栏」 |
| settings-layer | 设定的存放层级：用户层对所有项目生效；项目层只对当前项目生效、优先于用户层、项目受信任才生效；都没有时用内置默认值 | 简体「用户层」「项目层」 |
