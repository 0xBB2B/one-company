# 跨窗口 Agents 面板

## 目的
让用户在任意窗口看到并控制本工作区正在工作的需求代理及它们调用的角色，不被内部记录淹没。

## 逻辑
面板位于输入栏及原状态栏下方，是界面最后一块，原状态栏内容保持可见。
面板列出本工作区全部仓库的需求代理，每条以"仓库 · 需求标题"为首行，显示状态、真实活动、执行轮次与耗时，存在待答问题时显示标记，中断条目显示接管的活动 Shell 任务数，已停止条目显示清理未确认的 Shell 任务数；其子角色作为缩进子行显示角色名、任务标题、状态与活动。
活动来自守护进程推送的实际工具开始与结束事件，不由模型编造；守护进程不可达时显示不可达，不显示旧活动。
输入栏为空且无其他界面占用按键时按 ↓ 直接进入面板，没有面板时不抢按键；↑↓ 选条目、←→ 选按钮、Enter 执行、Tab 切换单项与批量、Esc 返回；Enter 在"查看"按钮上打开该会话的记录查看页。
控制按钮按状态提供：运行中有暂停与停止，已暂停有继续与停止，中断有续接与停止；任一窗口均可对本工作区任一运行操作。
聊天区不重复展示原始运行结果与生命周期通知，主会话仍收到完整结构化结果与中继通知。
面板限高可滚动；确认结束或用户停止的条目转灰色静态摘要，保留 20 秒后移出；临时操作失败提示显示 20 秒后恢复；计时自首次出现起算，重绘与选择不续时，新提示替换并重新计时。

## 约束
- C-1：当本工作区任一仓库存在需求代理时，系统应在原状态栏下方显示面板，条目为"仓库 · 需求标题"及其子角色缩进行，显示状态、真实活动、轮次、耗时与待答标记，中断条目另显示接管的活动 Shell 任务数，已停止条目另显示清理未确认的 Shell 任务数，不显示任务文件路径，不显示工作区外仓库。
- C-2：当守护进程推送工具开始或结束事件时，系统应更新对应条目的活动与统计；守护进程不可达时显示不可达，不用旧活动或编造进度冒充。
- C-3：当输入栏为空且没有补全菜单或其他页面占用按键时，系统应让 ↓ 直接进入面板；面板内 ↑↓ 选条目、←→ 选按钮、Enter 执行、Tab 切换批量、Esc 返回，选中按钮蓝色不附箭头；输入非空、其他页面占用或没有面板时不抢按键。
- C-4：当用户在任意窗口对本工作区任一运行执行暂停、继续、停止或续接时，系统应把请求送达对应守护进程并按真实结果更新状态，续接被拒时显示所列任务与原因，不以点击成功冒充执行完成。
- C-5：当运行回执、查询结果或生命周期通知产生时，系统应不在聊天区重复展示原始内容；主会话仍取得完整结果与通知。
- C-6：当条目超出面板容量时，系统应保持高度上限并允许滚动选择全部条目，不挤掉输入区域。
- C-7：当运行确认结束或被用户停止时，系统应把条目转为灰色静态摘要并保留真实结果，20 秒后移出；临时操作失败提示显示 20 秒后恢复正常提示；两者均自首次出现起计时，重绘与选择不续时，新提示替换并重新计时；暂停、中断与清理未确认的已停止运行不启动移除计时。

## 例子
用户在家打开新窗口，面板显示"backend · 订单导出"需求代理正在等待实现角色，子行显示实现角色正在编辑文件；用户选中该子行按暂停，20 秒前另一个已完成的需求代理条目仍为灰色摘要。

## 验收
### AC-1 布局与条目树 ← C-1
- 触发: 操作 在工作区内两个仓库各有需求代理且其中一个正调用两个角色时，从不同 worktree 打开两个窗口查看面板
- Given: 另有工作区外仓库的需求代理在运行，一个接管了两个活动 Shell 任务的中断需求代理，以及一个已停止但有一个 Shell 清理未确认的需求代理
- When: 对照两个窗口的面板位置与内容
- Then: 面板均位于原状态栏下方且原状态栏可见；两个仓库的需求代理均以"仓库 · 需求标题"显示，其子角色为缩进行；中断条目显示活动 Shell 任务数 2，已停止条目显示清理未确认 Shell 任务数 1；工作区外需求代理不显示；无任务文件路径

### AC-2 真实活动与不可达 ← C-2
- 触发: 操作 让一个角色依次读取、搜索并两次编辑同一文件，随后强杀守护进程
- Given: 工具事件可观察
- When: 观察面板更新
- Then: 活动与实际工具一致，文件数不报为两个；守护进程被杀后条目显示不可达而非继续显示编辑中

### AC-3 键盘进入与状态对应按钮 ← C-3
- 触发: 操作 从空输入按 ↓ 进入面板，选择运行中、已暂停与中断条目并按 Esc 返回；另测输入非空、设置页占用与没有面板时按 ↓
- Given: 三类条目均存在
- When: 观察焦点与按钮
- Then: 合法空输入 ↓ 直接进入面板；运行中显示暂停与停止，已暂停显示继续与停止，中断显示续接与停止，按钮蓝色无箭头；输入非空、页面占用或没有面板时不抢按键；Esc 返回输入栏

### AC-4 任意窗口控制以真实结果为准 ← C-4
- 触发: 操作 从非派出窗口对另一仓库的需求代理执行暂停，对一个 Shell 后代不会立即退出的运行执行停止，再对仍有活动遗留任务的中断运行执行续接
- Given: 三个运行均在本工作区
- When: 观察面板状态变化
- Then: 暂停在守护进程确认后才显示已暂停；停止在守护进程确认请求发出后显示用户停止，条目显示清理未确认的 Shell 任务数，不显示为运行中；续接被拒时显示所列任务与原因，状态仍为中断

### AC-5 聊天区去重 ← C-5
- 触发: 操作 派出需求代理并让其完成
- Given: 主会话需要结果做门禁
- When: 观察聊天区与主会话收到的内容
- Then: 聊天区无原始结构化运行数据与内部通知；主会话取得完整结果与中继通知

### AC-6 限高滚动 ← C-6
- 触发: 操作 增加条目直到超出面板容量并滚动选择末项
- Given: 终端尺寸固定
- When: 选择末项并操作
- Then: 面板不继续增高，输入区域可用，末项可选中并操作正确目标

### AC-7 结束灰显与临时提示 20 秒 ← C-7
- 触发: 操作 让运行分别成功、失败与被停止，触发一次操作失败提示，并在 5 秒后触发第二次；期间重绘与移动选择；另保留一个暂停与一个中断条目
- Given: 各事件首次出现时刻已知
- When: 在出现后立即、19 秒与 20 秒届满时观察
- Then: 结束条目立即转灰、19 秒仍在、20 秒移出；提示 19 秒可见、20 秒恢复，第二次提示替换并自新出现起重新计 20 秒；重绘与选择不续时；暂停与中断条目不被移出
