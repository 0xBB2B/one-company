# MCP 多选候选页

## 目的
让用户在角色设置页内为每个角色勾选可用的 MCP 服务，不必手工编辑配置。

## 逻辑
主页选中 MCP 字段按 Enter 后，在同一界面切换到标题为当前英文角色加“MCP 选择”的多选候选页；蓝色上下横线等于终端宽度、内容独立限宽，标题、列表、提示之间各一空行，无搜索区。
候选为宿主当前已配置的全部 MCP 服务，每行显示勾选标记与服务标识；已保存但当前未配置或被禁用的服务同样列出并标注“不可用”，可以取消勾选。宿主未配置任何服务且无已保存项时显示明确空态。
↑↓ 移动，Space 切换当前项勾选，Enter 确认，Esc 取消；提示为“↑↓ 选择 · Space 勾选 · Enter 确认 · Esc 取消”。
初始勾选状态来自当前保存范围的显式配置；当前范围未保存时，项目范围以全局列表为初始状态，全局范围为空。
确认后把勾选集合整体保存到当前范围，允许保存空集合以表示该角色不使用任何 MCP；取消不写配置。确认或取消均返回主页原角色 MCP 字段，不关闭重建界面。
只有持久化成功才提示保存成功；失败显示具体原因，原配置不变。保存仅影响后续启动的任务。

## 约束
- C-1：当用户在 MCP 字段按 Enter 时，系统应在同一界面打开当前角色的 MCP 多选候选页，候选为宿主当前已配置的全部服务加上已保存但不可用的服务，后者标注“不可用”；宿主未配置任何服务且无已保存项时显示明确空态而非报错。
- C-2：在候选页中，系统应以 ↑↓ 移动、Space 切换勾选、Enter 确认、Esc 取消；初始勾选反映当前范围的显式配置或其回退来源，取消不修改配置，确认或取消均原位返回主页原角色 MCP 字段，不关闭重建界面。
- C-3：当用户确认时，系统应把勾选集合整体保存到当前保存范围，允许空集合；持久化成功后主页 MCP 字段显示新值与来源，失败时显示具体原因且原配置不变。
- C-4：当已勾选服务当前不可用时，系统应保留其勾选并标注不可用，不自动剔除；用户在候选页取消勾选后保存才移除。

## 例子
用户在 worker 的 MCP 字段按 Enter，看到 context7、chrome-devtools、codegraph 三个候选，Space 勾选前两个后 Enter，主页 MCP 值行显示“context7, chrome-devtools”，来源为项目；之后宿主禁用 codegraph 不影响该配置。

## 验收
### AC-1 候选来源与不可用标记  ← C-1, C-4
- 触发: 操作 宿主配置 context7 与 chrome-devtools，先为 worker 勾选并保存 codegraph 后在宿主移除 codegraph，再打开 worker 的 MCP 候选页；另在宿主无任何 MCP 且无保存项时打开
- Given: 设置页可用，两种范围位置可写
- When: 查看候选列表
- Then: 列出 context7、chrome-devtools 与标注“不可用”且仍勾选的 codegraph，标题为“worker MCP 选择”，无搜索区；空环境显示明确空态而非报错或空白

### AC-2 勾选交互与原位返回  ← C-2
- 触发: 操作 在候选页用 ↑↓ 移动、Space 勾选两项并取消一项，分别以 Esc 取消和 Enter 确认
- Given: 当前范围已有一项显式勾选
- When: 观察初始勾选、按键响应及返回位置
- Then: 初始勾选与保存值一致；Space 只切换当前项；Esc 后配置不变，Enter 后配置为最终勾选集合；两种退出均返回主页原角色 MCP 字段，界面未关闭重建

### AC-3 整体保存与空集合  ← C-3
- 触发: 操作 在项目范围为 worker 确认三项勾选，再确认全部取消的空集合，重新打开设置页
- Given: 全局范围该角色已保存另一组勾选
- When: 查看主页 MCP 字段及重新打开后的值
- Then: 第一次保存后显示三项与项目来源；空集合保存后显示“无”且来源仍为项目，不回退到全局列表；重新打开后保存仍存在

### AC-4 保存失败不虚报  ← C-3
- 触发: 操作 在保存目标不可写时确认勾选
- Given: 保存前配置已知
- When: 系统处理保存
- Then: 显示具体失败原因，没有报告保存成功，主页仍显示原配置
