# 子运行暂停与继续

## 目的
让用户在准备断网或暂时不需要执行时暂停子代理，并在宿主保持打开时继续已有工作。

## 逻辑
用户暂停单个或全部子运行时立即请求取消当前操作，阻止对应运行继续开始模型请求和工具操作。
取消尚未确认时显示正在暂停，不能把发出请求当作已暂停；主会话仍能对话。
暂停保留会话上下文、已确认结果和任务进度，继续不是从原始任务起点重做。
中断的远端请求或工具不保证原地续传；已有副作用不撤销，结果不明的操作继续前先核对。
全部暂停仅针对当前主会话并阻止它继续派发新的子运行，不暂停其他窗口。
全部继续针对本会话所有已暂停子运行，包括单独暂停和连接故障暂停，并解除全部暂停造成的新派工阻止；不包含已停止或暂停尚未确认的运行。
实际连接故障只暂停受影响运行，网络恢复不会自动继续；暂停会话只要求在同次宿主运行期间保留。
正常退出及可处理的终端挂断必须清理工具；关闭终端不等于不可捕获的强杀。真正强杀或断电时不承诺执行退出回调。

## 约束
- C-1：当用户暂停一个子运行时，系统应立即请求取消当前操作并阻止后续执行，确认其不再继续执行后才显示已暂停；如果无法确认，应显示具体原因而非假报暂停成功。
- C-2：当用户在同次宿主运行内继续已暂停子运行时，系统应保留原任务进度、上下文与已确认结果；对结果不明的中断操作应先核对，不盲目重复有副作用的操作。
- C-3：当用户全部暂停时，系统应处理当前主会话的子运行并阻止新派工，不影响其他主会话或阻止用户与主会话对话；批量结果应如实区分已暂停与尚未确认的运行。
- C-4：如果某个运行遇到已识别的连接故障，系统应仅暂停受影响运行并显示原因，其他任务不因此整体暂停；认证失败、额度不足及业务失败不得冒充断网。
- C-5：当网络恢复时，系统应保持暂停，只有用户手动继续才恢复对应运行；暂停和停止控制本身不应依赖模型服务响应。
- C-6：当用户正常退出宿主或宿主处理可捕获的终端退出通知时，系统应停止暂停及运行中的子任务并确认受管理进程清理，保留已有文件与证据；真正强杀或断电不承诺退出回调，不能将普通关窗口归入强杀而跳过清理，也不承诺跨重启继续。
- C-7：当用户点击全部继续时，系统应对当前主会话所有已暂停子运行执行继续，包括此前单独暂停、连接故障暂停和全部暂停覆盖的运行，并解除批量暂停的新派工阻止；不继续已停止或未确认暂停的运行，不影响其他主会话，各运行继续失败时应分别显示原因。

## 例子
实现子代理已完成修改正在测试，用户暂停后准备断网；宿主保持打开，联网后手动继续，任务保留修改和上下文，核对中断测试后继续验证，不从头重复全部步骤。

## 验收
### AC-1 暂停须确认且不再推进 ← C-1
- 触发: 操作 在一个可取消操作执行中点击暂停，再对一个无法确认取消的操作点击暂停
- Given: 两个子运行均未完成，后续各有一个可观察写入操作
- When: 系统处理暂停请求
- Then: 可取消运行显示已暂停且不开始后续写入；未确认取消的运行显示正在暂停或具体不确定原因，不谎报成功

### AC-2 保留进度并核对副作用 ← C-2
- 触发: 操作 对已有文件修改和工具结果的运行暂停，再手动继续
- Given: 一个操作已完成，另一个操作在产生副作用后未返回确认
- When: 用户在宿主未关闭期间继续任务
- Then: 会话保留已确认结果和文件，继续前核对结果不明操作，不盲目重复该副作用，不从原任务起点重做全部工作

### AC-3 批量范围与新派工阻止 ← C-3
- 触发: 操作 在两个窗口均有任务时对其中一个窗口点击全部暂停
- Given: 当前主会话还有一个尚未派出的任务，另一窗口有运行中的任务
- When: 处理全部暂停并尝试在当前主会话继续派工
- Then: 当前范围如实显示各运行暂停结果且没有新子运行启动，另一窗口任务不受影响，当前主会话仍可对话

### AC-4 网络故障分类与局部影响 ← C-4
- 触发: 操作 分别让任务出现连接中断、认证失败、额度不足及业务失败
- Given: 同一主会话还有未受影响的本地任务
- When: 系统处理各类故障
- Then: 连接故障任务进入暂停处理并说明原因，其余错误保持真实类别，未受影响任务继续执行

### AC-5 联网不自动继续且离线可控制 ← C-5
- 触发: 操作 在断网时暂停任务，恢复网络后观察，再手动继续
- Given: 宿主保持打开且有可确认取消的运行
- When: 用户离线操作控制并随后恢复网络
- Then: 控制不等待模型回答，联网后没有自动继续，只有用户明确继续后才开始新的请求或工具操作

### AC-6 退出不保留后台写入 ← C-6
- 触发: 操作 在暂停和运行任务并存时分别执行 /quit、发送可捕获的终端退出通知并真实关闭终端
- Given: 各任务及工具已确认启动并产生修改和记录，测试不使用真正强杀替代普通关窗口
- When: 宿主处理正常退出、SIGHUP、SIGTERM 或实际终端关闭路径
- Then: 可处理退出路径清理对应受管理进程并保留成果；实际关窗验证其真实清理路径，紧急错误分支如实报告验证结论，不能用关闭输入通道或仅会话结束冒充清理成功，不承诺跨重启继续

### AC-7 全部继续覆盖所有已暂停原因 ← C-7
- 触发: 操作 分别单独暂停、触发连接故障暂停及全部暂停后，恢复网络并点击全部继续
- Given: 当前主会话包含三类已暂停运行、一个已停止和一个暂停不确定的运行，另一窗口也有暂停运行
- When: 用户手动执行全部继续并观察后续派工
- Then: 三类已暂停运行均按保留进度规则继续，新派工不再因全部暂停受阻；已停止、暂停不确定及其他窗口运行不被继续，个别失败如实显示而不虚报全部成功
