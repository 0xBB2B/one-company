# 子任务生命周期与续接

## 目的
让用户能在任务运行期间继续对话，又不会在退出主会话后留下不受管理的写入任务。

## 逻辑
普通聊天回合结束不停止子运行，主 agent 仍可接收该运行的完成通知、查询结果或请求取消。
用户取消任务、新建或切换主会话、正常退出宿主或宿主处理可捕获的终端退出通知时，系统停止对应子任务及其受管理进程，保留已经产生的文件改动和执行证据。
新建或切换主会话须先确认旧子运行及其 Shell 清理完成；无法确认则阻止完成切换并报告具体原因，不让旧任务在不可见会话中继续执行。
普通关闭终端需验证真实退出路径，不直接等同强杀；真正强杀或断电不承诺宿主执行清理回调。
只有确认停止后才能报告取消或中断完成；无法确认停止时明确显示状态不确定，不把该运行当作成功。
子任务异常退出时记录失败原因，不把最后一段自然语言或不完整结果当作完成证据。
执行 /pi-spec:resume 时先核对原运行状态、已有结果和工作区；不重复执行已完成任务，不在原运行仍可能写入时重复派工。
系统不自动回滚中断前的修改，也不让子任务脱离主会话继续运行。

## 约束
- C-1：当主 agent 的普通聊天回合结束而宿主仍运行时，系统应保持未完成子任务运行，并在其结束后将对应运行的结果通知主 agent。
- C-2：当用户取消任务、新建或切换主会话、宿主正常退出或处理可捕获的终端退出通知时，系统应停止相应子任务并确认受管理进程清理，保留已修改文件和执行证据；确认后才报告取消或中断完成并放行会话切换，清理无法确认时阻止完成切换并说明原因，普通关窗不能被当作真正强杀而跳过清理。
- C-3：如果子任务异常退出或无法确认其已停止，系统应显示具体失败或不确定原因，不得将其判为成功或启动可能与之重复写入的任务。
- C-4：当用户执行 /pi-spec:resume 时，系统应先核对原运行、已有结果和工作区，再续接未完成任务，不自动回滚改动、不重跑已完成任务。

## 例子
实现任务已写好测试时用户关闭宿主；子任务停止，测试文件保留。再次打开宿主执行 /pi-spec:resume，系统核对中断状态及文件改动后继续处理未完成任务，而不是把中断当作通过或清空修改。

## 验收
### AC-1 回合结束不等于取消  ← C-1
- 触发: 操作 派工一个延迟完成的任务后结束主 agent 当前聊天回合
- Given: 宿主保持运行，子任务尚未完成
- When: 等待子任务正常结束
- Then: 子任务继续运行到结束，主 agent 收到与原运行标识对应的完成通知和结果

### AC-2 取消及退出停止任务并保留修改  ← C-2
- 触发: 操作 在子任务写入已授权测试文件后，分别取消任务、执行 /quit、发送 SIGHUP 或 SIGTERM 并真实关闭终端
- Given: 每次操作前子任务及其受管理进程已确认运行，测试文件已写入，不以关闭输入通道替代真实关窗
- When: 系统处理取消、正常退出或实际终端退出路径
- Then: 可处理路径中的受管理进程停止且成果保留，取消或中断不等于任务成功；实际关窗及其紧急分支如实验证，无法确认清理时明确报告，不要求真正强杀或断电后执行回调

### AC-3 异常与停止不确定时失败关闭  ← C-3
- 触发: 操作 让子任务异常退出，或让系统无法确认旧任务已停止
- Given: 子任务没有完整的成功结果，旧任务可能已经修改文件
- When: 查询运行并尝试续接同一任务
- Then: 查询显示具体失败或不确定原因，没有判为成功；停止状态不确定时没有启动重复写入任务

### AC-4 续接核对原运行与工作区  ← C-4
- 触发: 命令 /pi-spec:resume
- Given: 一个任务已完成，另一个任务已确认中断且留下文件修改和执行证据
- When: 主 agent 处理续接
- Then: 已完成任务没有重跑，中断任务在核对原运行和工作区后续接，原有修改没有被自动回滚

### AC-5 新建与切换会话先停止旧子运行 ← C-2
- 触发: 操作 在旧主会话有活跃子运行及其后台 Shell 时分别执行 /new 和切换已有会话，另测试清理无法确认
- Given: 旧子运行已产生文件，另一窗口也有活跃子运行
- When: 观察旧子运行、Shell 活动、切换结果及保留文件
- Then: 旧子运行及其 Shell 确认停止后才完成切换，另一窗口不受影响且文件保留；清理无法确认时不完成切换、不报告旧运行成功，并显示具体原因
