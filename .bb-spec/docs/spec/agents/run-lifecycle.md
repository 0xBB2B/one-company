# 运行生命周期与续接

## 目的
让用户随时关窗或切换会话而不打断需求代理，又不留下不受管理的写入任务。

## 逻辑
需求代理与角色运行在守护进程内，主会话回合结束、窗口关闭、/new 或切换会话都不影响它们；完成与阻塞经中继通知。
窗口新建或切换会话时只清理该窗口主会话自己的 Shell，确认清理后才完成切换；无法确认则阻止并说明原因。
守护进程崩溃、被强杀或机器重启导致运行无法确认已停止时，运行标记为中断并保留文件改动与会话记录，不判为成功、不自动重跑。
用户在任意窗口对中断运行选择续接时，先核对原运行状态、会话记录与工作区，再从会话文件重载并接续；仍可能写入或停止不明时不重复派工，不自动回滚改动。
角色异常退出时记录失败原因，不把最后一段自然语言或不完整结果当作完成证据。

## 约束
- C-1：当主会话回合结束、窗口关闭、新建或切换会话时，系统应保持守护进程内的需求代理与角色继续运行，并在其结束后经中继通知主会话。
- C-2：当窗口新建或切换会话时，系统应先停止并确认清理该窗口主会话自己的 Shell，确认后才完成切换；无法确认时阻止切换并说明原因；不停止守护进程内的运行。
- C-3：如果守护进程崩溃、被强杀或机器重启，系统应把其中运行标记为中断，保留文件改动与会话记录，不判为成功、不自动重跑。
- C-4：当用户续接中断运行时，系统应先核对原运行、会话记录与工作区，再重载会话接续；仍可能写入或停止不明时不重复派工，不自动回滚改动，不重跑已完成任务。
- C-5：如果角色异常退出或无法确认已停止，系统应显示具体失败或不确定原因，不判为成功，也不启动可能重复写入的任务。

## 例子
用户派出需求代理后执行 /new 并关闭窗口；需求代理在守护进程内继续，worker 完成后需求代理推进任务。晚上机器重启，用户次日在新窗口看到"中断"，点续接后系统核对工作区并从会话文件重载继续。

## 验收
### AC-1 关窗与切换不影响运行 ← C-1
- 触发: 操作 派出需求代理后依次结束回合、执行 /new、切换会话并关闭窗口
- Given: 需求代理及其角色尚未完成
- When: 在新窗口观察运行
- Then: 运行持续到结束，主会话经中继收到对应身份的完成通知

### AC-2 切换只清理窗口自身 Shell ← C-2
- 触发: 操作 在主会话有后台 Shell 且守护进程内有角色 Shell 时执行 /new，另测清理无法确认
- Given: 两类 Shell 均持续活动
- When: 观察切换结果
- Then: 主会话 Shell 确认停止后切换完成，守护进程内 Shell 继续；清理无法确认时切换被阻止并显示原因

### AC-3 中断标记与保留 ← C-3
- 触发: 操作 在角色写入文件后强杀守护进程，再重新拉起
- Given: 写入已发生
- When: 查询运行
- Then: 运行显示中断及原因，文件与会话记录保留，未判成功也未自动重跑

### AC-4 续接核对与重载 ← C-4
- 触发: 操作 对已完成任务、中断任务与停止不明任务分别请求续接
- Given: 中断任务有会话记录与文件改动
- When: 系统处理续接
- Then: 已完成任务不重跑；中断任务核对后从会话文件重载接续且改动未回滚；停止不明任务不派工并显示原因

### AC-5 异常退出失败关闭 ← C-5
- 触发: 操作 让角色在只输出自然语言后异常退出
- Given: 没有合法结构化结果
- When: 查询运行并尝试推进任务
- Then: 显示具体失败，任务未完成，未启动重复写入运行
