# 运行生命周期与续接

## 目的
让用户随时关窗或切换会话而不打断需求代理，又不留下不受管理的写入任务。

## 逻辑
需求代理与角色运行在守护进程内，主会话回合结束、窗口关闭、/new 或切换会话都不影响它们；完成与阻塞经中继通知。
窗口新建或切换会话只涉及该窗口主会话自己的 Shell，守护进程内的运行照常进行。
守护进程崩溃、被强杀或机器重启时其中运行被标记为中断，文件改动与会话记录保留。
用户在任意窗口对中断运行选择续接时，先核对该运行接管的 Shell 任务、会话记录与工作区：仍有活动或不确定任务时拒绝并列出这些任务，全部结束后才从SQLite 会话记录重载并接续；不自动回滚改动。遗留任务自行退出或被用户停止后，再次续接即可通过。
角色异常退出时记录失败原因，不把最后一段自然语言或不完整结果当作完成证据。

## 约束
- C-1：当主会话回合结束、窗口关闭、新建或切换会话时，系统应保持守护进程内的需求代理与角色继续运行，并在其结束后经中继通知主会话。
- C-2：当用户续接中断运行时，系统应先核对该运行接管的 Shell 任务、会话记录与工作区；存在活动或不确定任务时拒绝续接并列出任务与原因，运行状态保持中断；全部结束后重载会话接续，不自动回滚改动，不重跑已完成任务。
- C-3：如果角色异常退出或无法确认已停止，系统应显示具体失败或不确定原因，不判为成功，也不启动可能重复写入的任务。

## 例子
用户派出需求代理后执行 /new 并关闭窗口；需求代理在守护进程内继续，实现角色完成后需求代理推进任务。晚上机器重启，用户次日在新窗口看到"中断"，点续接后系统核对工作区并从SQLite 会话记录重载继续。另一次守护进程被强杀时实现角色的开发服务还在运行，续接被拒并列出该任务；用户在 Shell 列表停止它后再点续接即通过。

## 验收
### AC-1 关窗与切换不影响运行 ← C-1
- 触发: 操作 派出需求代理后依次结束回合、执行 /new、切换会话并关闭窗口
- Given: 需求代理及其角色尚未完成
- When: 在新窗口观察运行
- Then: 运行持续到结束，主会话经中继收到对应身份的完成通知

### AC-2 续接核对与重载 ← C-2
- 触发: 操作 对已完成任务、遗留任务已结束的中断任务、仍有活动遗留任务的中断任务分别请求续接，再停止遗留任务后重试
- Given: 中断任务有会话记录与文件改动
- When: 系统处理续接
- Then: 已完成任务不重跑；遗留已结束的中断任务核对后从SQLite 会话记录重载接续且改动未回滚；有活动遗留任务的续接被拒并列出任务，状态仍为中断；停止遗留任务后重试通过

### AC-3 异常退出失败关闭 ← C-3
- 触发: 操作 让角色在只输出自然语言后异常退出
- Given: 没有合法结构化结果
- When: 查询运行并尝试推进任务
- Then: 显示具体失败，任务未完成，未启动重复写入运行
