# 同进程独立子会话执行

## 目的
让主会话直接管理子代理会话和事件，减少额外宿主进程而保持任务隔离与控制边界。

## 逻辑
各子运行与主会话在同一个宿主进程内执行，不为每个子代理启动独立宿主进程或守护进程。
每次派工具有独立运行身份、对话历史、角色权限、有效模型配置、状态与结果，不自动共享其他会话的任务上下文。
事件和控制对应明确的子运行；暂停、继续和用户停止只作用于指定运行或当前主会话的批量范围。
子运行正常结束、失败或停止时释放它的会话资源和监听，不退出主宿主，不清除其他子运行。
命令工具仍可能创建外部进程，同进程会话不作为外部工具已停止的证明；正常退出和用户停止必须确认受管理工具清理，无法确认时如实报告，不放行重复写入。
真正强杀或断电不承诺宿主执行清理回调；普通终端关闭需验证可处理信号及实际退出路径，不能直接当作强杀排除。
创建或配置失败应明确返回错误，不切换到另一套子代理执行方式或擅自更换模型及权限。

## 约束
- C-1：当主会话启动多个子运行时，系统应在主宿主进程内创建彼此独立的会话，不额外启动逐子代理宿主或守护进程，各运行身份、对话历史和结果应互不混淆。
- C-2：当子会话执行任务时，系统应维持角色工具、文件范围、该角色的 MCP 服务集合及启动时有效模型和思考等级，不因共享宿主进程而继承其他会话权限或未授权上下文。
- C-3：当单个子运行暂停、继续、正常结束、失败或被用户停止时，系统应只更新对应状态，最终结束时释放其会话资源，不退出主宿主或中断其他正常子运行；暂停仍须保留可继续的上下文。
- C-4：如果会话创建失败、配置不可用或工具停止无法确认，系统应报告对应原因并保持失败或不确定，不启动替代执行方式、不伪造停止成功；正常退出及可处理终端退出路径应清理本次受管理工具并保留成果，真正强杀或断电不承诺清理回调。

## 例子
两个实现任务在同一宿主中并行，用户停止其中一个；它转为用户停止并释放会话资源，另一个继续执行，主会话仍可对话，进程列表没有额外的子代理宿主。

## 验收
### AC-1 同进程执行且上下文独立 ← C-1
- 触发: 操作 在一个主会话启动两个具有不同任务标记的子运行
- Given: 宿主可用，两个任务都不需要启动命令进程且没有授权互相共享历史
- When: 观察执行进程、运行身份及各自对话和结果
- Then: 子代理执行属于同一个主宿主进程，没有逐任务额外宿主或守护进程，两个运行身份不同且任务标记和结果不串入另一会话

### AC-2 角色配置与权限不扩张 ← C-2
- 触发: 操作 给两个角色设置不同有效配置并派工，再让其请求各自未授权的文件或工具
- Given: 每个角色均有明确配置及任务范围，其他会话具有不同权限
- When: 查询实际配置并执行允许及越权操作
- Then: 各运行使用启动时自己的配置，合法操作可执行，越权操作被拒绝，不借用其他会话权限或擅自选择另一个模型

### AC-3 单运行控制不退出整个宿主 ← C-3
- 触发: 操作 在两个子运行并存时对其中一个暂停继续，再分别验证正常结束、执行失败和用户停止
- Given: 主会话保持打开，另一个子运行仍有待完成工作
- When: 处理所选运行的各类控制和结束事件
- Then: 暂停继续保留该运行上下文，最终结束释放其资源和监听，另一运行仍可推进，主会话仍可对话，不执行整个宿主退出

### AC-4 故障及外部工具清理不被绕过 ← C-4
- 触发: 操作 分别制造会话初始化失败、无效配置及无法确认停止的工具，再验证有工具运行时退出宿主
- Given: 没有授权替代执行方式，任务已产生的文件应保留
- When: 系统处理故障或正常退出及可处理终端退出通知
- Then: 明确报告真实失败或不确定且不替代派工、不放行重复写入；可处理退出执行并核对工具清理，保留文件，不能只凭同进程会话结束宣称所有工具已停止，也不将普通关窗冒充真正强杀
