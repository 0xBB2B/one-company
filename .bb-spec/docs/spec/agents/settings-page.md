# 角色设置页面

## 目的
让用户在紧凑的终端界面内配置角色，不必手工编辑配置内容。

## 逻辑
用户执行角色设置命令后，在输入栏位置打开内容区紧凑限宽的单页界面；主页与各候选页由等于终端宽度的上下横线包住标题至底部提示，内部无横线，内容区独立限宽且窄屏不超宽，调整终端宽度后两者分别适应。
主页依次为标题、保存范围行、角色标签行、模型区、思考区、MCP 区与操作提示；范围行同时显示全局与项目并用方括号标出当前范围；角色标签按角色目录顺序列出全部角色（含需求代理），当前角色同样用方括号标出。
模型、思考、MCP 三个区各由字段标题与值行组成：字段标题带灰色的当前来源（默认、全局或项目），值行缩进显示实际生效值；模型显示完整标识，MCP 值行列出已勾选服务、无勾选时显示"无"、不可用项标注不可用；仅选中字段的值行使用蓝色底色。
高度足够时横线紧邻首尾内容，各区块之间一行空白，标题与范围行之间不插空行；宽度足够时操作提示为一行；高度不足先收缩空白保证操作内容可见。
左右键切换角色，上下键选择字段，Tab 原位切换全局或项目范围且不写配置，Enter 进入当前字段候选；整个设置只打开一次界面，视图切换不关闭重建，不因退出重进而闪屏；只有主页 Esc 才关闭整个设置。
模型与思考候选页标题为当前角色名加候选类型；模型候选允许输入文字搜索，包含宿主已注册模型与沿用主会话；思考候选仅包含有效模型支持的等级与沿用上级默认。候选初始定位当前显式项或对应沿用项而不是沿用的实际生效值，直接确认沿用项仍保持沿用。
MCP 候选页为多选、无搜索区：候选为当前窗口探测到的适配器配置中的全部服务，加上已保存但当前未配置或被禁用的服务并标注不可用，后者可取消勾选；未探测到服务且无已保存项时显示明确空态。↑↓ 移动，Space 切换当前项，Enter 确认，Esc 取消。初始勾选来自当前范围的显式配置；当前范围未保存时，项目范围以全局列表为初始状态，全局范围为空。
任一候选确认后立即把所选值整体保存到当前范围（MCP 允许空集合表示不使用任何服务），Esc 取消不写配置；确认或取消均返回主页原角色原字段。
只有持久化成功后才提示保存成功并刷新字段的值与来源；失败明确显示原因，不虚报成功，不破坏原有配置。设置页不提供最大并发配置。

## 约束
- C-1：当用户打开设置时，系统应展示内容独立限宽、上下横线全终端宽、内部无横线的单页界面，主页依次为标题、同时显示两种范围并括住当前范围的范围行、角色目录全部角色标签（含需求代理，当前角色括住）、模型区、思考区、MCP 区与操作提示；每个字段的标题带灰色来源，值行缩进显示实际生效值，模型为完整标识，MCP 为已勾选服务列表或"无"且不可用项标注不可用；仅选中值行使用蓝底；高度不足先收缩空白，窄屏仍保持操作可达且不超宽。
- C-2：当用户在主页按键时，系统应以左右键切换角色、上下键切换字段、Tab 原位切换范围且不写配置并保持当前角色与字段、Enter 进入当前字段候选、Esc 关闭设置；整个设置只打开一次界面，视图切换不关闭重建，不因退出重进而闪屏。
- C-3：当用户在模型或思考字段按 Enter 时，系统应在同一界面切换到标题为当前角色加候选类型的候选页；模型候选可输入搜索且包含已注册模型与沿用主会话，思考候选仅包含有效模型支持的等级与沿用项；初始定位当前显式项或对应沿用项而非沿用的实际生效值，直接确认沿用项仍保持沿用；确认或 Esc 取消后返回主页原角色原字段，取消不写配置。
- C-4：当用户在 MCP 字段按 Enter 时，系统应在同一界面打开当前角色的多选候选页，候选为当前窗口探测到的适配器配置中的全部服务加上已保存但不可用的服务并标注不可用；未探测到服务且无已保存项时显示明确空态而非报错；↑↓ 移动、Space 切换勾选、Enter 确认、Esc 取消；初始勾选反映当前范围的显式配置或其回退来源；已勾选的不可用项保留勾选，用户取消勾选后确认才移除；确认或取消均返回主页原角色 MCP 字段。
- C-5：当用户在任一候选页确认时，系统应把所选值整体保存到当前保存范围，MCP 允许空集合；持久化成功后主页字段显示新值与来源；如果当前环境不支持交互页面或保存失败，系统应显示具体原因，不报告保存成功，不破坏原有配置。
- C-6：当设置页面展示或保存配置时，系统应不提供最大并发配置，也不创建任何并发数量上限。

## 例子
用户打开角色设置，用右键切到审查角色标签，用 Tab 选择项目范围，按 Enter 进入审查角色的模型候选并搜索确认模型；返回审查角色的模型字段，标题显示项目来源。下移到 MCP 字段按 Enter，看到 context7、chrome-devtools、codegraph 三个候选，Space 勾选前两个后 Enter，主页 MCP 值行显示这两项且来源为项目；重新打开后保存仍存在。

## 验收
### AC-1 聚焦布局与来源展示 ← C-1
- 触发: 命令 /pi-company:setting
- Given: 交互终端有可用模型，各角色存在不同配置和来源，至少一个角色已勾选 MCP 且其中一项当前不可用
- When: 分别在足高宽屏、窄屏与高度不足的终端打开设置并切换角色
- Then: 足高宽屏主页依次为上横线、标题、范围行、空行、全部角色标签、空行、模型区、空行、思考区、空行、MCP 区、空行、一行操作提示、下横线；范围行同时显示两种范围并仅括住当前范围，当前角色括住；各字段标题带灰色来源，值行缩进且为实际生效值，MCP 值列出已勾选服务并对不可用项标注、无勾选显示"无"；仅选中值行蓝底；横线全终端宽、内容独立限宽，窄屏不超宽且操作可达，高度不足先压空白

### AC-2 主页按键与单一界面 ← C-2
- 触发: 操作 用左右键遍历角色、上下键选择字段、Tab 切换范围，再按 Esc
- Given: 全局和项目配置位置可写
- When: 观察角色与字段位置、配置内容及界面重绘
- Then: 切范围原位保持当前角色与字段且不写配置；全程同一界面无关闭重建或闪屏；主页 Esc 关闭设置

### AC-3 模型与思考候选搜索、定位与原位返回 ← C-3
- 触发: 操作 在当前角色模型与思考字段分别按 Enter
- Given: 已注册支持思考与不支持思考的模型，角色分别存在显式配置与沿用配置
- When: 在模型候选输入搜索，分别确认显式项、直接确认沿用项及按 Esc 取消
- Then: 候选页标题为当前角色加候选类型，模型搜索显示匹配候选，思考候选不超出模型能力；初始定位当前显式项或沿用项，确认沿用不固化生效值；确认或取消均原位返回原角色原字段，取消不保存

### AC-4 MCP 候选来源、勾选交互与不可用标记 ← C-4
- 触发: 操作 宿主配置 context7 与 chrome-devtools，先为实现角色勾选并保存 codegraph 后在宿主移除 codegraph，再打开该角色的 MCP 候选页用 ↑↓ 移动、Space 勾选两项并取消一项，分别以 Esc 取消和 Enter 确认；另在宿主无任何 MCP 且无保存项时打开
- Given: 当前范围已有显式勾选
- When: 查看候选列表、初始勾选、按键响应及返回位置
- Then: 列出 context7、chrome-devtools 与标注不可用且仍勾选的 codegraph，无搜索区；初始勾选与保存值一致，Space 只切换当前项；Esc 后配置不变，Enter 后配置为最终勾选集合；两种退出均返回主页原角色 MCP 字段；空环境显示明确空态而非报错或空白

### AC-5 整体保存、空集合与失败不虚报 ← C-5
- 触发: 操作 在项目范围为实现角色确认三项 MCP 勾选，再确认全部取消的空集合并重新打开设置页；另在非交互环境打开设置，以及在保存目标不可写时确认勾选
- Given: 全局范围该角色已保存另一组勾选，保存前配置已知
- When: 查看主页字段及重新打开后的值，观察失败反馈
- Then: 第一次保存后显示三项与项目来源；空集合保存后显示"无"且来源仍为项目，不回退到全局列表；重新打开后保存仍存在；非交互环境与不可写目标均显示具体失败原因，没有报告保存成功，原配置内容保持不变

### AC-6 页面不设置并发数量限制 ← C-6
- 触发: 操作 打开设置页并保存任一角色的有效模型配置
- Given: 目录中各角色均可配置
- When: 检查页面选项与保存后的配置
- Then: 页面没有最大并发字段，保存结果没有新增角色级或全局并发数量上限
