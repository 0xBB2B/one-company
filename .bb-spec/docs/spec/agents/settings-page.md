# 角色设置页面

## 目的
让用户在紧凑的终端界面内配置角色，不必手工编辑配置内容。

## 逻辑
用户输入 /pi-spec:setting 后打开内容区紧凑限宽的单页界面；主页与各候选页的蓝色上下横线始终等于终端可用宽度，内容区独立限宽且窄屏不超宽，调整终端宽度后两者分别适应。
主页标题独占一行为“pi-spec · 角色设置”，紧接下一行显示“保存范围 [全局] 项目”或“保存范围 全局 [项目]”，两种范围始终显示且当前范围用方括号标出；其下按角色目录顺序排列全部角色标签（含需求代理），当前角色同样用方括号标出；字段标题为“模型 - 来源 默认”、“思考 - 来源 默认”和“MCP - 来源 默认”或对应实际来源，实际生效值另起一行缩进两个空格，MCP 值行列出已勾选服务、无勾选显示“无”、不可用项标注“不可用”，不硬编码示例等级。
高度足够时，蓝线紧邻首尾内容；主页标题及范围、标签、模型、思考、MCP、操作提示六个区块之间各一行空白，标题与范围之间不插空行；宽度足够时操作提示为一行。模型候选、思考候选与 MCP 候选的布局不因主页变化而改变；高度不足先收缩空白保证操作内容可见。
左右键切换角色，上下键选择模型、思考或 MCP 字段，Tab 切换全局或项目范围，Enter 进入候选；当前角色突出显示，仅选中字段的值行使用蓝色底色。
主页与各候选页仅由蓝色上下横线包住标题至底部提示，内部无横线；整个设置只打开一次界面，视图切换不关闭重建，不因退出重进而闪屏。
候选标题使用当前英文角色加“模型选择”、“思考选择”或“MCP 选择”；模型搜索占位为“搜索：输入模型名”，模型候选允许输入文字搜索，初始定位当前选项；模型可选宿主已注册模型或沿用主会话，显式思考候选仅包含有效模型支持的等级；MCP 候选为多选。
沿用模型时定位“沿用主会话”，未显式设置思考时定位“使用上级/角色默认”，不将实际生效值当作已固定值；直接确认沿用项仍保持沿用。
候选 Esc 取消并返回原角色原字段，确认后也返回原角色原字段；主页 Esc 才关闭整个设置。
选择确认后立即保存到当前范围，页面显示中文保存范围与来源，仅影响后续启动任务，不提供最大并发配置。
只有持久化成功后才提示保存成功；失败明确显示原因，不虚报成功，不破坏原有配置。

## 约束
- C-1：当用户打开设置时，系统应展示内容独立限宽且上下蓝线全终端宽的单页界面；主页依次为独立标题“pi-spec · 角色设置”、紧接的“保存范围 [全局] 项目”或“保存范围 全局 [项目]”、角色目录中全部角色标签（含需求代理）、模型区、思考区、MCP 区及操作提示，各区块间一行空白、边界紧邻首尾内容；当前角色用方括号突出，字段标题为“模型 - 来源 默认”、“思考 - 来源 默认”或“MCP - 来源 默认”（来源随配置变化且灰色显示），值另行缩进两个空格，模型为完整标识，MCP 值为已勾选服务标识列表或“无”且不可用项标注“不可用”，不显示服务商说明或独立来源行，仅选中值行蓝底；左右切角色、上下切字段、Tab 原位切范围且不保存，角色字段保持；宽度足够时提示合为“←→ 角色 · ↑↓ 字段 · Tab 范围 · Enter 修改 · Esc 关闭”一行；窄屏仍保持操作可达且不超宽，高度不足先缩空白，内部无横线，不关闭重建或因退出重进闪屏。
- C-2：当用户在模型或思考字段按 Enter 编辑时，系统应在同一界面切换到模型或思考候选，两者均仅用等于终端宽度的蓝色上下横线包住标题至提示，内容区保持独立限宽；标题使用当前英文角色加“模型选择”或“思考选择”，模型页依次为标题、搜索、列表、提示，各区块间一空行、蓝线紧邻首尾内容，搜索占位为“搜索：输入模型名”，提示为“↑↓ 选择 · 输入搜索 · Enter 确认 · Esc 取消”；思考页无搜索区，提示不含输入搜索，标题、列表、提示间各一空行；模型候选可输入搜索，包含已注册模型和沿用主会话，显式思考候选仅包含有效模型支持等级；初始定位当前显式项或对应沿用项而非沿用的实际生效值，直接确认沿用项仍保持沿用；确认或 Esc 取消后返回原角色原字段，不关闭重建或因退出重进而闪屏，取消不写配置，只有主页 Esc 才关闭设置。在 MCP 字段按 Enter 时同一界面切换到该角色的 MCP 多选候选。
- C-3：当设置页面展示或保存配置时，系统应不提供最大并发配置，也不创建任何并发数量上限。
- C-4：如果当前环境不支持交互页面或配置保存失败，系统应显示具体原因，不报告保存成功，不破坏原有配置。

## 例子
用户打开 /pi-spec:setting，用右键切到 reviewer 标签，用 Tab 选择项目范围，按 Enter 进入“reviewer 模型选择”并搜索确认模型；返回 reviewer 的模型字段，标题显示项目来源；下移到 MCP 字段看到“无”，重新打开后保存仍存在。

## 验收
### AC-1 聚焦布局与指定范围保存  ← C-1
- 触发: 命令 /pi-spec:setting
- Given: 交互终端有可用模型，全局和项目配置位置可写，各角色存在不同配置和来源，至少一个角色已勾选 MCP 且其中一项当前不可用
- When: 在宽屏和窄屏打开设置，用左右键遍历角色、上下键选择字段、Tab 切换范围，在两种范围分别修改配置并重新打开
- Then: 足高宽屏主页依次为上蓝线、独立标题、保存范围行、空行、角色目录全部英文标签、空行、“模型 - 来源”标题、缩进两格完整模型值、空行、“思考 - 来源”标题、缩进两格实际思考值、空行、“MCP - 来源”标题、缩进两格已勾选服务列表（不可用项标注“不可用”，无勾选为“无”）、空行、规定的一行完整操作提示、下蓝线；范围行同时显示全局和项目并仅括住当前范围，来源灰色、当前角色方括号突出且仅选中值行蓝底；边界全终端宽、内容独立限宽，高度不足先压空白；切范围原位保持角色字段且不写配置、不闪屏，确认后配置与来源正确、其他角色不变

### AC-2 候选搜索、定位与原位返回  ← C-2
- 触发: 操作 在当前角色模型、思考与 MCP 字段分别按 Enter
- Given: 已注册支持思考与不支持思考的模型，角色分别存在显式配置与沿用配置
- When: 打开三种候选，在模型候选输入搜索，分别确认显式项、直接确认沿用项及按 Esc 取消，最后在主页按 Esc
- Then: 足高模型页依次为上蓝线、英文角色加“模型选择”、空行、搜索行、空行、候选列表、空行、规定提示、下蓝线；思考页标题为英文角色加“思考选择”，无搜索区或搜索提示，标题/列表/提示之间各一空行；MCP 字段进入英文角色加“MCP 选择”的多选候选；边界全终端宽、内容独立限宽且随尺寸适应，模型搜索显示匹配候选，思考候选不超出模型能力；初始定位当前显式项或沿用项，确认沿用不固化生效值；确认或取消原位返回原角色原字段，取消不保存；全程同一界面且切换无退出重进或闪屏，仅主页 Esc 关闭

### AC-3 页面不设置并发数量限制  ← C-3
- 触发: 操作 打开设置页并保存任一角色的有效模型配置
- Given: 目录中各角色均可配置
- When: 检查页面选项与保存后的配置
- Then: 页面没有最大并发字段，保存结果没有新增角色级或全局并发数量上限

### AC-4 不支持界面或保存失败时不虚报成功  ← C-4
- 触发: 操作 在非交互环境调用 /pi-spec:setting，或在保存目标不可写时尝试保存
- Given: 保存前的配置已知
- When: 系统处理页面打开或保存请求
- Then: 显示具体失败原因，没有报告保存成功，原配置内容保持不变
