# 会话记录查看页

## 目的
让用户随时看到某个需求代理或角色正在思考什么、输出了什么，而不必进入它的会话对话。

## 逻辑
在面板条目的"查看"按钮上按 Enter，在输入栏位置打开该会话的记录查看页，保持原状态栏与面板的相对顺序，不使用浮层或全屏页。
页面按时间顺序显示该会话的思考内容、模型输出、工具调用与结果摘要，默认跟随最新内容；↑↓ 与翻页键滚动，滚动后停止跟随，回到底部恢复跟随；Esc 返回面板原选中位置。
内容来自守护进程的实时事件流；已保存的记录来自本机用户数据区的会话记录，会话已结束或守护进程不可达时显示该记录，并标明"已结束"或"不可达"状态。
页面只读，不提供输入、作答或控制入口；内容原样展示不作改写。
页面限高可滚动，关闭后恢复输入栏。

## 约束
- C-1：当用户在面板条目上选择查看并按 Enter 时，系统应在输入栏位置打开该会话的记录查看页，保持底部其他区块顺序，不打开浮层或全屏页；Esc 返回面板并恢复原选中位置。
- C-2：当会话运行中时，系统应按时间顺序实时显示思考、输出、工具调用与结果摘要并默认跟随最新；用户滚动后停止跟随，回到底部恢复跟随。
- C-3：当会话已结束或守护进程不可达时，系统应显示已保存的会话记录并标明对应状态，不显示为运行中。
- C-4：当查看页展示内容时，系统应只读、不提供输入或控制入口，内容原样展示不作改写。

## 例子
用户在面板选中正在写测试的 worker 行按"查看"，看到它的思考与刚写入的测试文件摘要实时滚动；按 Esc 回到面板，选中位置仍在该 worker 行。

## 验收
### AC-1 打开与返回 ← C-1
- 触发: 操作 在面板第三个条目上按查看，再按 Esc
- Given: 面板可见
- When: 观察页面位置与关闭后的焦点
- Then: 查看页替换输入栏且底部其他区块顺序不变，没有浮层或全屏；Esc 后回到面板且第三个条目仍被选中

### AC-2 实时跟随与滚动 ← C-2
- 触发: 操作 打开运行中会话的查看页，向上滚动三页，再回到底部
- Given: 会话持续产生思考、输出与工具事件
- When: 观察内容更新
- Then: 打开时按时间顺序显示并跟随最新；滚动后新内容不改变视口，回到底部后恢复跟随

### AC-3 结束与不可达显示保存记录 ← C-3
- 触发: 操作 分别打开已结束会话的查看页，以及在查看运行中会话时强杀守护进程
- Given: 两个会话均有已保存的会话记录
- When: 观察页面内容与状态
- Then: 已结束会话显示完整保存记录并标明已结束；守护进程被杀后页面标明不可达并保留已保存内容，不显示运行中

### AC-4 只读与原样展示 ← C-4
- 触发: 操作 让会话的工具结果中包含测试凭据与独立标记文本，打开查看页并尝试输入文字
- Given: 凭据与标记文本可在输出中核对
- When: 检查页面内容与按键响应
- Then: 凭据与标记文本原样显示，文字输入与控制操作均无效果，没有作答入口
