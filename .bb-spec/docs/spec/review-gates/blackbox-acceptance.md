# 黑盒验收

## 目的
让黑盒验收回答“功能做全了吗、真的能用吗”，不经过多步编排，需求代理只核对验收者的结构化对象与其写出的报告，一致才接受需求。

## 逻辑
需求代理以一次直接调用派工黑盒验收者，输入为规则文件清单、唯一验收报告的指定位置、运行环境的启动方式和验收结果的结构化格式。
派工指令要求验收者不读取源码、任务文件与其他仓库文件，只依据规则文件的逻辑、例子与验收条目在真实运行环境中操作；该要求由指令约束，命令层不作保证。
验收者逐条执行验收并比对输出，同时以使用者视角检查规则描述的入口是否存在且可达、按例子操作能否走通、错误场景的提示是否可理解并指向正确的下一步、功能是否只在验收条目的精确输入下才成立。
验收者先写入指定报告，再提交唯一结构化对象；报告含可用性观察、逐条结果与验收过程中执行的全部命令。验收者的命令造成工作区写入时，该次验收失败并记违规。
需求代理只读取该报告做一致性核对，从不转录、覆盖或回滚它。

## 约束
- C-1：当系统执行黑盒验收时，系统应由需求代理以一次直接调用派工黑盒验收者，不为该验收启动多步编排，并仅依据结构化对象的裁决、逐条结果与指定报告的一致性决定是否接受需求。
- C-2：当系统派工黑盒验收者时，系统应在派工指令中要求其不读取源码、任务文件与其他仓库文件，验收依据只来自规则文件与真实环境的可观察行为。
- C-3：当系统执行黑盒验收时，系统应把功能是否完善、是否可用作为验收关注点，并在报告中记录可用性观察。
- C-4：如果规则文件描述的功能在真实环境缺失、不可达、不可用，或只在验收条目的精确输入下才成立，系统应把验收结论置为不通过并写明具体原因，即使逐条验收全部通过。
- C-5：当系统执行黑盒验收时，系统应仅允许黑盒验收者写入指定位置的验收报告，报告须列出验收过程中执行的全部命令；需求代理不得转录、覆盖或回滚该报告。
- C-6：如果验收者的任一命令造成工作区写入，系统应把该次验收判为失败并记录违规。
- C-7：当验收者返回通过时，系统应要求逐条结果非空且全部通过、问题清单与未覆盖项为空、报告位置精确等于指定位置，且报告结论为通过，四者缺一即不接受需求。
- C-8：如果验收者已写入报告但结构化校验失败或与报告不一致，系统应保留本次报告作为诊断证据，不接受需求，并显示具体差异。

## 例子
规则文件描述“命令行工具支持导出报表”，验收条目只给了一个固定日期。验收者按条目操作通过，换成规则例子中的日期范围时命令报错且提示不可理解；报告记录该可用性问题与全部执行命令，结论为不通过，需求代理核对对象与报告一致后不接受需求，界面上没有多步编排。

## 验收
### AC-1 直接调用并以结构化对象裁决 ← C-1, C-7
- 触发: 操作 执行需求黑盒验收
- Given: 黑盒验收者作为门禁被需求代理直接调用
- When: 验收者提交语义符合约定的通过对象，且报告位置与结论一致
- Then: 界面没有为该验收显示多步编排，需求被接受

### AC-2 派工指令约束验收依据 ← C-2
- 触发: 操作 执行黑盒验收并查看验收者收到的派工指令
- Given: 仓库中存在源码、任务文件与配置文件
- When: 验收者被派工
- Then: 派工指令包含不读取源码、任务文件与其他仓库文件的要求，验收输入只有规则文件清单、报告位置、环境启动方式与结构化格式

### AC-3 逐条通过但不可用即不通过 ← C-3, C-4
- 触发: 操作 让规则文件描述的功能只在验收条目的精确输入下成立
- Given: 逐条验收全部通过，按规则例子中的其他输入操作时功能报错
- When: 验收者完成验收并写出报告
- Then: 报告的可用性观察记录该问题，结论为不通过，需求不被接受

### AC-4 报告由验收者唯一写入并列出命令 ← C-5, C-8
- 触发: 操作 执行黑盒验收并让验收者写入指定报告后不提交结构化对象
- Given: 已指定唯一验收报告位置并保存其调用前内容
- When: 验收者写入本次报告后以说明文字结束而未提交对象
- Then: 指定位置保留验收者写入的本次报告且报告列出其执行的全部命令，需求代理不转录、覆盖或恢复调用前内容，需求不被接受

### AC-5 结果与报告不一致时拒绝 ← C-7, C-8
- 触发: 操作 让黑盒验收者提交通过，但报告位置不同或报告结论为不通过
- Given: 需求处于验收阶段，验收者已写入本次报告
- When: 需求代理核对提交对象与指定报告
- Then: 本次报告保留，需求不被接受，界面显示对象与报告不一致的具体内容

### AC-6 验收者写入工作区即失败 ← C-6
- 触发: 操作 让验收者在验收过程中执行一条修改仓库文件的命令
- Given: 验收前后的工作区内容可核对
- When: 该命令结束
- Then: 该次验收判为失败并记录违规，需求不被接受
