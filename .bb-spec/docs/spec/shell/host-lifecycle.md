# Shell 宿主生命周期

## 目的
让 Shell 的存续范围与启动它的宿主一致：窗口主会话的 Shell 随窗口会话，需求代理与角色的 Shell 随守护进程内对应运行。

## 逻辑
主会话普通聊天回合结束不结束该会话，主会话的后台 Shell 可继续运行；守护进程内需求代理与角色的 Shell 不受窗口回合、关窗或切换影响。
子运行完成、失败或被停止时清理自己的 Shell，不把 Shell 自动转交主会话，也不影响其他运行。
暂停子运行时停止其 Shell，保留上下文与文件；继续时不自动重启命令，结果不明的副作用先核对。
新建或切换会话时先停止旧窗口主会话自己的 Shell，确认清理后才完成切换；失败时保留旧现场和具体原因；守护进程内的 Shell 不因此停止。
窗口正常退出、普通关闭终端及可处理的退出信号清理该窗口主会话的 Shell；守护进程正常退出时清理其内全部运行的 Shell。
真正强杀、宿主崩溃或断电不承诺执行清理，不通过独立看护在宿主消失后补做清理。
只有任务及其后代停止均得到确认才报告清理完成；主命令退出不等于所有后代已退出。

## 约束
- C-1：在主会话仍保持打开期间，系统应允许主 agent 的后台 Shell 跨越普通聊天回合继续运行；子运行完成、失败或停止时应清理该运行的 Shell，不自动转移归属，不停止其他宿主的 Shell。
- C-2：当子运行被暂停时，系统应停止其 Shell 并确认不再执行后才报告暂停，保留已有成果；继续后不自动重启命令，结果不明的中断操作应先核对实际影响。
- C-3：当用户新建或切换会话时，系统应先停止旧窗口主会话自己的 Shell，确认清理后完成切换；如果清理无法确认，应报告具体原因并阻止完成切换，不把残留任务隐藏在旧会话中。
- C-4：当正常退出、普通关窗或可处理退出信号发生时，系统应清理该窗口主会话的 Shell 并保留已产生的文件，守护进程内运行的 Shell 不受影响；守护进程自身正常退出时清理其内全部 Shell；真正强杀、宿主崩溃或断电不承诺清理，不以这些例外跳过普通关窗验证。
- C-5：如果命令已退出而后代仍在运行，或系统无法确认任务及后代已经停止，系统应继续按原归属管理并显示活动或具体不确定原因，不提前报告清理完成或删除该未确认任务。

## 例子
实现子代理后台启动一个辅助服务，完成任务时服务随之停止；主 agent 自己启动的服务仍在运行。用户随后新建会话，主服务在旧会话完成清理后停止，新会话不继承这些进程。

## 验收
### AC-1 结束范围遵循真实宿主 ← C-1
- 触发: 操作 主 agent 与两个子运行各启动后台命令，结束主 agent 一轮回复，再分别让一个子运行完成、失败或被停止
- Given: 各命令持续产生可观察活动，另一子运行与主会话仍保持运行
- When: 观察普通回复结束及子运行各结束路径后的命令活动
- Then: 普通回复结束没有停止主 Shell；结束子运行的 Shell 及后代停止，归属未转移，其他子运行和主会话 Shell 继续运行

### AC-2 暂停与继续不重启命令 ← C-2
- 触发: 操作 暂停含后台 Shell 和结果不明写入操作的子运行，再手动继续
- Given: 运行已产生文件修改，命令的启动次数可观察
- When: 查看暂停结果及继续后的操作
- Then: Shell 确认停止后才报告已暂停，原文件保留；继续不自动再次启动命令，结果不明操作先核对而不盲目重做

### AC-3 会话切换以清理确认为前提 ← C-3
- 触发: 操作 在主会话 Shell 与守护进程内角色 Shell 均运行时分别执行 /new 和切换已有会话，并另测清理无法确认的情况
- Given: 旧会话及另一窗口各有持续执行的命令
- When: 观察切换结果、旧 Shell 活动及新会话的 Shell 列表
- Then: 旧主会话 Shell 确认停止后切换完成，新会话不继承旧进程，守护进程内角色 Shell 与另一窗口不受影响；清理无法确认时切换被阻止并显示原因，旧任务仍可识别

### AC-4 可处理退出路径清理真实进程 ← C-4
- 触发: 操作 分别对窗口执行 /quit、发送 SIGHUP 与 SIGTERM、真实关闭终端，对守护进程执行正常退出，并单独对照真正强杀
- Given: 每条路径均有已启动且持续产生活动的窗口主会话 Shell、守护进程内角色 Shell 和已写入文件，普通关窗不以关闭输入通道替代
- When: 检查宿主处理退出后的进程活动与文件
- Then: 可处理路径中窗口主会话的 Shell 及后代停止、守护进程内 Shell 不受窗口退出影响，守护进程正常退出时其 Shell 停止，文件保留；真正强杀不被宣称执行了退出清理，普通关窗不能借强杀例外免测

### AC-5 主命令退出不能隐藏后代 ← C-5
- 触发: 操作 让主命令启动独立后代后迅速退出，再结束其宿主；另制造无法确认停止的情况
- Given: 后代仍持续执行，原任务编号和宿主已知
- When: 查看列表并请求清理
- Then: 后代没有因主命令退出而失去归属；全部停止后才报告清理完成，无法确认时保留任务与具体原因而不虚报零残留
