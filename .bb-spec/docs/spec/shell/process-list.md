# Shell 管理列表与简洁详情

## 目的
让用户在输入栏位置查看本窗口与本工作区守护进程内的具体 Shell 和宿主，不用展开底部面板或离开当前聊天界面。

## 逻辑
/ps 与 Shell 汇总行回车使用同一界面，像角色设置页一样临时替换输入栏，不采用居中浮层、全屏页面或汇总行下面展开。
列表一行代表一个 Shell 任务，显示任务编号、具体宿主（本窗口主会话，或守护进程内需求代理、角色及其运行身份）、状态、耗时和命令；任意窗口可对本工作区任一 Shell 请求停止，选中行蓝色突出且不附箭头。
同角色不同子运行通过独立身份区分，不能仅写 worker 而让用户无法判断是哪次运行。
↑↓ 选择，Enter 查看详情，K 请求停止，Esc 关闭；停止确认及详情都在同一输入栏区域切换。
详情只显示任务身份、宿主、状态、命令、工作目录、PID、耗时和 Esc 返回列表，不提供输出查看、停止按钮或左右选择操作提示。
列表超过可视容量时限高并滚动，关闭后恢复输入栏；从汇总行打开的页面关闭后回到汇总行选择位置。
空列表明确说明当前没有活动 Shell；读取失败显示具体原因，不以空列表替代错误。

## 约束
- C-1：当用户执行 /ps 或在 Shell 汇总行回车时，系统应在输入栏位置打开同一个管理页，保持原状态栏、Shell 汇总与 Agents 的相对顺序，不在汇总行下展开或打开居中浮层及全屏页；关闭后恢复输入栏，从汇总行进入时恢复该入口焦点。
- C-2：在 Shell 列表中，系统应一行展示一个任务及其编号、具体宿主、状态、耗时、命令，蓝色突出选中行且不附箭头；↑↓ 选择、Enter 进入详情、K 请求停止、Esc 关闭，按键不得同时操作 Agents，详情或确认页不额外叠加弹窗。
- C-3：当用户查看 Shell 详情时，系统应只展示任务身份、宿主、状态、完整命令、目录、PID 和耗时，并仅提示 Esc 返回列表；不显示查看输出或停止 Shell 按钮，不显示左右选择操作及 Enter 执行提示。
- C-4：当列表超过可视容量或没有活动 Shell 时，系统应分别提供限高滚动或明确空态，列表增长不无限扩高；如果读取失败或选择期间目标结束，应显示具体错误或真实结束状态，不用其他任务的详情冒充原目标。

## 例子
用户从汇总行打开 Shell 列表，看见同属 worker 的两个任务各有不同宿主标识；回车查看长命令的完整信息，再按 Esc 回到原列表，不出现输出查看按钮。

## 验收
### AC-1 两个入口共用输入栏管理页 ← C-1
- 触发: 操作 分别通过 /ps 和汇总行回车打开列表，再关闭
- Given: 当前主会话有 Shell 与 Agents，原输入栏、状态栏和汇总行位置可观察
- When: 对照打开方式、页面位置和关闭后的焦点
- Then: 两个入口打开同一管理页且仅临时替换输入栏，原底部内容相对顺序不变；没有居中浮层、全屏页或汇总行下展开，关闭恢复输入栏，从汇总行进入时回到汇总行选择位置

### AC-2 每行归属可辨且按键不串界面 ← C-2
- 触发: 操作 在两个 worker 和主 agent 各有 Shell 时打开列表，选择各行、查看详情并发起再取消停止
- Given: 两个 worker 有不同运行身份，Agents 同时可见
- When: 查看行字段、选中效果和各层按键响应
- Then: 每个 Shell 恰占一行且字段齐全，两个 worker 的具体身份可区分；选中行蓝色且无箭头，按键只作用于 Shell 页面，详情与停止确认在输入栏区域切换，取消不停止进程

### AC-3 详情只读且无冗余操作 ← C-3
- 触发: 操作 选择带长命令的 Shell 后按 Enter，再按 Esc
- Given: 任务的宿主、目录、PID、命令和启动时间均已知
- When: 检查详情内容及按键提示
- Then: 身份与状态信息正确，完整命令可读，仅提示 Esc 返回列表；没有查看输出、停止 Shell 按钮及左右操作、Enter 执行提示，Esc 返回列表

### AC-4 长列表空态与异常不冒充其他任务 ← C-4
- 触发: 操作 增加 Shell 直到超出可视容量并滚动到末项，另查看空列表、读取失败及详情目标自行结束的情况
- Given: 终端尺寸固定，目标任务身份已知
- When: 观察高度、末项可达性及三种边界反馈
- Then: 列表限高且末项可选择，空列表显示没有活动 Shell；读取失败显示具体错误，目标结束显示真实结束状态而不换成其他任务，终端高度不足时仍可返回
