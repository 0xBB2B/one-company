# 固定任务机械检查

## 目的
让可机械判定的规划要求由固定程序一致检查，避免反复生成检查脚本和误算验收范围。

## 逻辑
用户或流程通过固定检查入口指定一个需求，检查其变更清单及任务集合。
检查范围以本次新增或修改的规则为验收覆盖基准，不把整个项目的其他验收加入本次必需集合。
检查任务格式、编号、索引、文件归属、依赖、验收引用、原文一致性及非空验证方式。
生产文件类别由可核对的声明和项目约定确定；无法确认类别时明确报错，不默默排除数量限制。
检查只读取输入，成功返回零退出码；失败返回非零退出码与可定位的原因。
固定检查不会执行任务验证命令、自动修正文档或把形式合格当作行为正确。

## 约束
- C-1：当用户调用任务机械检查时，系统应提供稳定的调用方式，并核对每任务至多两个生产文件、至多三条验收引用、正文计数上限、固定格式、索引及非空业务规则和验证方式。
- C-2：当检查关联关系时，系统应拒绝重复归属的生产文件、向后或不存在的依赖、依赖环、额外的并行标记字段、缺失或错误验收引用，以及与所引用约束和验收原文不一致的内容。
- C-3：当检查验收覆盖时，系统应覆盖本次新增或修改规则的全部验收，不把变更范围外的未覆盖验收误报为本次缺项；未知规则或引用仍须报错。
- C-4：如果任何机械条件不满足或输入无法读取、分类时，系统应返回非零退出码并定位任务、字段或缺项；检查前后输入不变，不执行验证命令、不自动修复、不推断行为已正确。

## 例子
需求只调整暂停规则，其他设置规则没有任务引用不构成本次错误；暂停规则漏掉一条验收时，固定检查明确报告该缺项。

## 验收
### AC-1 正确任务稳定通过且不扩大范围 ← C-1, C-3, C-4
- 触发: 操作 对一个有效需求连续两次调用固定任务机械检查入口
- Given: 全部本次验收已覆盖，另有未列入本次变更的规则；一个任务恰有二百行需计数内容并包含不计入的成品代码块
- When: 两次执行检查
- Then: 两次均返回零退出码，不误报其他规则验收或代码块行数，输入逐字不变，任务验证命令未执行，结果明确只证明机械条件

### AC-2 不合法任务准确拒绝 ← C-1, C-2, C-4
- 触发: 操作 逐项提交超限、缺字段、缺索引、归属冲突、依赖错误、额外并行字段、原文不符、未知引用及不可读取或分类的独立案例
- Given: 各案例仅改变一个被检查条件，能够核对检查前的输入和验证命令执行次数
- When: 对各案例调用相同检查入口
- Then: 每个案例均返回非零退出码并定位对应条件，没有修改输入或执行任务验证命令；增加一行使二百行变为二百零一行的案例也被拒绝

### AC-3 本次验收遗漏不能通过 ← C-2, C-3
- 触发: 操作 删除一个本次新增规则验收的最后一处任务引用后执行检查
- Given: 其余引用、原文、格式及文件归属均合法
- When: 检查本次验收覆盖
- Then: 返回非零退出码并报告具体缺失验收，不因已有其他验收映射而通过
