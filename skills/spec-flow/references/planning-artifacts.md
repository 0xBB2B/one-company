# 规划产物核对清单

需求代理核对规划角色产出的任务集合时使用的清单，只核对产物是否体现要素，不重复定义要素本身的成立标准。

## 骨架五要素在场

核对任务索引与任务协作说明是否分别体现下列五个要素的名称对应内容，只核对是否在场：

- 行为切片
- 文件归属
- 真实依赖
- 运行入口切换节点
- 验证边界

任一名称对应的内容缺失，视为骨架未完整落地，退回规划角色补齐，需求代理不代写。

## 高风险任务验证方案核对

涉及状态控制、安全边界、宿主接入或不可重复副作用的任务，在实施前由需求代理核对验证方案；验证条件无法确认时列出具体缺项，不判为实施就绪。

核对时排除下列三类伪证据，任一类都不得替代真实验证：

- 模拟通过：未真实运行验证入口，只描述预期会通过。
- 模型自觉遵守提示：仅依赖执行角色声称会遵守约束，没有可运行的检查支撑。
- 既有测试数量：仅以既有测试用例数量作为证据，未指向本次变化对应的验证入口。

## 产物形态核对

产物中不得出现临时编写的检查脚本、任务生成器或验收解析器；机械检查只能调用既有固定入口。发现此类产物时退回规划角色重写，不代为改写。

验证入口必须可运行：核对引用的命令、页面操作或对外契约确实存在且可执行，不接受只有文字描述而没有对应可运行入口的验证约定。

模拟边界须把本次改动引入或修改的连接、鉴权与保护逻辑排除在模拟之外，不得连同外部边界一起模拟掉。
